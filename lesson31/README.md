# 第31章 午前Ⅱドリル

第9〜26章のネットワーク本編を、4つの分野別ドリル（計40問）で横断的に総仕上げする章です。弱点が見つかったら本編の該当章に戻り、仕上げは手持ちの午前Ⅱ過去問で行いましょう。

## 1. L2・L3技術ドリル

本編の第10章（イーサネット）・第11章（VLAN・STP）・第12章（IPアドレッシング）・第13章（ルーティング）の総仕上げです。落とし穴トップ3は、①/nのサブネットのホスト数は「2の(32−n)乗−2」で、ネットワークアドレスとブロードキャストアドレスの2つを引き忘れない、②STPのルートブリッジは値が「最小」のブリッジが選ばれる、③経路選択はメトリックの比較よりも先にロンゲストマッチが適用される、です。L2はMACアドレス・L3はIPアドレスで転送するという階層の整理を確かめてから、午前Ⅱの過去問に進みましょう。

### 確認問題

**問1.** L2スイッチが受信したユニキャストフレームの宛先MACアドレスがMACアドレステーブルに学習されていない場合の動作はどれでしょう？

1. フレームを破棄する
2. デフォルトゲートウェイに転送する
3. 受信したポートを除く全ポートにフレームを送出する（フラッディング）
4. 送信元にエラーを通知する

<details><summary>答えと解説</summary>

正解: **3**

未学習の宛先へのフレームは、受信ポート以外の全ポートへフラッディングされます。宛先の機器が応答するとその送信元MACアドレスが学習され、以降は該当ポートだけに転送されます。破棄やエラー通知は行わず、デフォルトゲートウェイはL3（IP）の概念なのでスイッチのフレーム転送には関係しません。

</details>

**問2.** IEEE802.1Qの説明として、適切なものはどれでしょう？

1. 複数の物理リンクを束ねて1本の論理リンクとして扱う規格
2. イーサネットフレームにVLAN IDを示すタグを挿入し、1本のリンクで複数VLANのフレームを伝送する規格
3. 無線LANでポート単位の利用者認証を行う規格
4. ループを検出して一部のポートをブロックする規格

<details><summary>答えと解説</summary>

正解: **2**

802.1Qはフレームに4バイトのタグを挿入してVLAN IDを示し、トランクリンク上で複数VLANのフレームを多重化する規格です。物理リンクを束ねるのはリンクアグリゲーション、ポート単位の認証はIEEE802.1X、ループ対策はスパニングツリー（STP）の説明です。

</details>

**問3.** スパニングツリープロトコル（STP）の目的として、適切なものはどれでしょう？

1. フレームを暗号化して盗聴を防ぐ
2. VLAN間の通信を中継する
3. トラフィックを複数リンクに分散して帯域を拡大する
4. 物理的にループのあるL2ネットワークで一部のポートをブロックし、論理的にループのない構成を作る

<details><summary>答えと解説</summary>

正解: **4**

STPはブリッジ間でBPDUを交換してルートブリッジを決め、冗長リンクの一部をブロッキング状態にしてループを防ぎます。ループが残るとブロードキャストフレームが回り続けるブロードキャストストームが発生します。暗号化の機能はなく、VLAN間の中継はL3の役割、帯域の拡大はリンクアグリゲーションの目的です。

</details>

**問4.** 192.168.1.64/26のサブネットで、ホストに割り当てられるIPアドレスの数はいくつでしょう？

1. 62個
2. 64個
3. 126個
4. 30個

<details><summary>答えと解説</summary>

正解: **1**

/26のホスト部は32−26＝6ビットなので、アドレスは2の6乗＝64個です。そこからネットワークアドレスとブロードキャストアドレスの2個を除いた62個がホストに割り当てられます。64個は2個を引き忘れた値で、126個は/25、30個は/27の場合のホスト数です。

</details>

**問5.** 172.16.10.0/23のネットワークにおけるブロードキャストアドレスはどれでしょう？

1. 172.16.10.255
2. 172.16.11.255
3. 172.16.10.0
4. 172.16.255.255

<details><summary>答えと解説</summary>

正解: **2**

/23は第3オクテットの最下位1ビットまでがホスト部に含まれるため、範囲は172.16.10.0〜172.16.11.255の2つのオクテット分です。その末尾である172.16.11.255がブロードキャストアドレスになります。172.16.10.255は範囲の途中にある普通のホストアドレス、172.16.10.0はネットワークアドレス、172.16.255.255は/16とみなした場合の値です。

</details>

**問6.** ルーティングテーブルに10.0.0.0/8、10.1.0.0/16、10.1.1.0/24の3つの経路があるとき、宛先10.1.1.5のパケットに使われる経路はどれでしょう？

1. 10.0.0.0/8
2. 10.1.0.0/16
3. 10.1.1.0/24
4. 3経路は等価なので負荷分散される

<details><summary>答えと解説</summary>

正解: **3**

宛先に複数の経路がマッチする場合は、プレフィックス長が最も長い経路を選ぶロンゲストマッチが適用され、10.1.1.0/24が使われます。/8や/16の経路もマッチはしますがプレフィックスが短いため選ばれず、プレフィックス長の異なる経路間で負荷分散が行われることはありません。

</details>

**問7.** OSPFの特徴として、適切なものはどれでしょう？

1. 各ルータがリンク状態情報（LSA）を交換してトポロジを共有し、そこから最短経路を計算するリンクステート型プロトコルである
2. 経由するルータ数（ホップ数）だけで経路を選び、最大15ホップまでという制限がある
3. AS間の経路制御に使われ、パス属性に基づいて経路を選択する
4. 経路情報の交換は行わず、管理者がすべての経路を手動で設定する

<details><summary>答えと解説</summary>

正解: **1**

OSPFはリンクステート型のプロトコルで、LSAで共有したトポロジ情報からダイクストラ法で最短経路を計算し、コストは帯域幅を基に決まります。ホップ数のみの判断と15ホップ制限はRIP、AS間の経路制御とパス属性はBGP、手動設定は静的経路の説明です。

</details>

**問8.** BGPの説明として、適切なものはどれでしょう？

1. 同一AS内部の経路を高速に収束させることを目的とするプロトコルである
2. UDP上で動作し、定期的に経路表全体をブロードキャストする
3. 隣接ルータをブロードキャストで自動発見して経路交換を始める
4. AS間の経路制御に用いられ、TCPのコネクション上で設定したピアと経路情報を交換する

<details><summary>答えと解説</summary>

正解: **4**

BGPはインターネットにおけるAS間ルーティングプロトコルで、設定したピアとTCP（ポート179番）の接続を確立し、経路とパス属性を交換します。AS内部の経路制御はOSPFなどIGPの役割です。BGPはUDPではなくTCPを使い、隣接の自動発見ではなく明示的なピア設定を基本とします。

</details>

**問9.** VRRPの説明として、適切なものはどれでしょう？

1. 複数のルータが同時にパケットを転送して帯域を拡大するプロトコル
2. 複数のルータで仮想ルータを構成し、マスタの障害時にバックアップが仮想IPアドレスを引き継ぐプロトコル
3. ルータ同士が経路情報を交換するためのプロトコル
4. 複数のルータへ設定を一括配布するためのプロトコル

<details><summary>答えと解説</summary>

正解: **2**

VRRPでは、デフォルトゲートウェイとなる仮想IPアドレス（と仮想MACアドレス）を複数のルータで共有し、優先度の最も高いマスタが転送を担当して、障害時にはバックアップが引き継ぎます。目的は帯域の拡大ではなくゲートウェイの冗長化で、経路情報の交換や設定配布の機能ではありません。

</details>

**問10.** IPv6の説明として、適切なものはどれでしょう？

1. アドレス長は64ビットである
2. 通信相手の探索にはブロードキャストを多用する
3. アドレス長は128ビットで、同一リンク内の通信にはfe80::/10のリンクローカルアドレスが使われる
4. IPv4アドレスが枯渇した場合にだけ一時的に使われる補助プロトコルである

<details><summary>答えと解説</summary>

正解: **3**

IPv6のアドレスは128ビットで、各インタフェースは必ずリンクローカルアドレス（fe80::/10）を持ちます。64ビットはプレフィックスとインタフェースIDの境界としてよく使われる長さであってアドレス全長ではありません。また、IPv6にブロードキャストはなくマルチキャストで代替され、IPv4とは独立した正式なプロトコルです。

</details>

## 2. プロトコルドリル

本編の第14章（TCP/UDP）・第15章（DNS）・第16章（DHCP・NAT）・第17章（HTTP・メール）の総仕上げです。落とし穴トップ3は、①フロー制御（受信側の都合＝ウィンドウ）と輻輳制御（ネットワークの都合）の区別、②DNSの再帰問い合わせ（クライアント→キャッシュDNSサーバ）と反復問い合わせ（キャッシュDNSサーバ→権威DNSサーバ）の向き、③NAPTは「ポート番号まで変換するから1つのグローバルIPアドレスを共有できる」という理屈、です。25・53・80・443などの主要ポート番号も即答できる状態にして、過去問へ進みましょう。

### 確認問題

**問1.** TCPのコネクション確立（3ウェイハンドシェイク）におけるパケットのやり取りの順序として、正しいものはどれでしょう？

1. SYN → SYN/ACK → ACK
2. ACK → SYN → SYN/ACK
3. SYN → ACK → SYN/ACK
4. SYN → SYN → ACK

<details><summary>答えと解説</summary>

正解: **1**

クライアントがSYNを送り、サーバが確認応答と接続要求を兼ねたSYN/ACKを返し、最後にクライアントがACKを返す3段階で、互いの初期シーケンス番号を確認し合います。ほかの順序では相手のシーケンス番号に対する確認応答が成立せず、コネクションを確立できません。

</details>

**問2.** TCPのウィンドウ制御の説明として、適切なものはどれでしょう？

1. ネットワークの混雑を検知して経路を切り替える仕組み
2. 1セグメント送信するごとに必ず確認応答を待つ仕組み
3. ポート番号によって宛先のアプリケーションを識別する仕組み
4. 受信側が通知した受信可能な量の範囲内で、確認応答を待たずに複数のセグメントを連続して送信する仕組み

<details><summary>答えと解説</summary>

正解: **4**

ウィンドウ制御では受信側が受信バッファの空き（ウィンドウサイズ）を通知し、送信側はその範囲までACKを待たずに連続送信することで、効率と受信側の保護を両立します。1セグメントごとに応答を待つ方式は効率が悪く、ウィンドウ制御の説明ではありません。経路の切り替えはルーティング、アプリケーションの識別はポート番号そのものの役割です。

</details>

**問3.** UDPが音声通話などのリアルタイム通信に適している理由として、適切なものはどれでしょう？

1. 確認応答と再送によって信頼性を保証するから
2. コネクション確立や再送を行わず、遅延を小さくできるから
3. 暗号化の機能を標準で内蔵しているから
4. 順序制御によって大容量データを正しく並べ替えられるから

<details><summary>答えと解説</summary>

正解: **2**

UDPはコネクションレスで、確認応答・再送・順序制御を行わないため遅延が小さく、多少の欠落より速さが重要な音声・映像などに向きます。確認応答・再送や順序制御はTCPの機能であり、UDP自体に暗号化の機能はありません。

</details>

**問4.** DNSのMXレコードが示す情報はどれでしょう？

1. ホスト名に対応するIPv4アドレス
2. IPアドレスからホスト名を引くための情報
3. そのドメイン宛てのメールを受け取るメールサーバのホスト名
4. そのゾーンを管理する権威DNSサーバのホスト名

<details><summary>答えと解説</summary>

正解: **3**

MX（Mail eXchange）レコードは、ドメイン宛てメールの配送先となるメールサーバを優先度付きで指定します。IPv4アドレスを示すのはAレコード、IPアドレスからの逆引きはPTRレコード、権威DNSサーバを示すのはNSレコードです。

</details>

**問5.** DNSのリソースレコードに設定されるTTLの意味として、適切なものはどれでしょう？

1. そのレコードをキャッシュとして保持してよい時間
2. パケットが経由できるルータ数の上限
3. ゾーン転送を行う間隔
4. ドメイン名の登録の有効期限

<details><summary>答えと解説</summary>

正解: **1**

DNS応答のTTLは、キャッシュDNSサーバなどがそのレコードを保持してよい秒数で、これを過ぎると再度問い合わせが必要になります。経由ルータ数の上限はIPヘッダのTTL、ゾーン転送の間隔はSOAレコードのrefresh値、ドメイン名の有効期限は登録管理の話であり、いずれもレコードのTTLとは別のものです。

</details>

**問6.** DHCPリレーエージェントの役割として、適切なものはどれでしょう？

1. DHCPサーバが払い出せるアドレスの範囲を拡張する
2. クライアントがブロードキャストするDHCP要求を、別セグメントにあるDHCPサーバへユニキャストで転送する
3. 複数のDHCPサーバ間で設定を同期する
4. 特定のMACアドレスに常に同じIPアドレスを割り当てる

<details><summary>答えと解説</summary>

正解: **2**

DHCPの発見（DISCOVER）はブロードキャストで行われるため、そのままではルータを越えられません。リレーエージェントがこれを受け取り、別セグメントのDHCPサーバへユニキャストで中継することで、サーバを集中配置できます。アドレス範囲の拡張やサーバ間の同期は別の話で、特定MACアドレスへの固定割り当ては予約（静的割当て）の機能です。

</details>

**問7.** NAPT（IPマスカレード）の説明として、適切なものはどれでしょう？

1. プライベートIPアドレスとグローバルIPアドレスを1対1で変換する
2. MACアドレスとIPアドレスの対応を解決する
3. ホスト名をIPアドレスに変換する
4. 送信元IPアドレスとポート番号の組を変換し、複数の内部ホストで1つのグローバルIPアドレスを共有できるようにする

<details><summary>答えと解説</summary>

正解: **4**

NAPTはIPアドレスに加えてポート番号まで変換・管理するため、変換表で各通信を区別でき、1つのグローバルIPアドレスを多数の内部ホストが同時に使えます。1対1の変換はNAT、MACアドレスとIPアドレスの対応解決はARP、名前解決はDNSの役割です。

</details>

**問8.** HTTPはステートレスなプロトコルですが、ログイン状態の維持に広く使われている仕組みはどれでしょう？

1. TCPのシーケンス番号
2. 送信元IPアドレスによる利用者の識別
3. サーバが発行したセッションIDをCookieとしてブラウザが毎回送信する仕組み
4. DNSのキャッシュ

<details><summary>答えと解説</summary>

正解: **3**

サーバはセッションIDをCookieとしてブラウザに渡し、ブラウザは以降のリクエストで毎回それを送るため、サーバは同じ利用者からのアクセスだと識別できます。TCPのシーケンス番号はコネクション単位の情報でリクエストをまたいだ識別には使えず、送信元IPアドレスはNAPTで複数人に共有されるため利用者の識別には不向きで、DNSキャッシュは名前解決の仕組みです。

</details>

**問9.** 電子メールのプロトコルの役割分担として、適切なものはどれでしょう？

1. SMTPはメールの送信・転送に使われ、POP3は受信メールを端末へダウンロードするために使われる
2. SMTPは受信専用、POP3は送信専用のプロトコルである
3. IMAPはメール本文を暗号化するためのプロトコルである
4. POP3はサーバ上にメールを置いたままフォルダ管理することを標準の使い方とする

<details><summary>答えと解説</summary>

正解: **1**

SMTPが送信とサーバ間の転送、POP3が端末へのダウンロードによる受信、IMAPがサーバ上にメールを置いたまま管理・閲覧という役割分担です。SMTPとPOP3の役割を逆にした説明は誤りで、IMAP自体は暗号化プロトコルではなく（暗号化はTLSの併用で実現）、サーバ上での管理はPOP3ではなくIMAPの特徴です。

</details>

**問10.** HTTPS（HTTP over TLS）が使うウェルノウンポートはどれでしょう？

1. 80番
2. 443番
3. 25番
4. 53番

<details><summary>答えと解説</summary>

正解: **2**

HTTPSは443番ポートを使います。80番は平文のHTTP、25番はSMTP、53番はDNSのポート番号です。主要プロトコルのポート番号は午前Ⅱでは即答できるようにしておきましょう。

</details>

## 3. セキュリティドリル

本編の第19章（暗号・PKI）・第20章（FW・DMZ）・第21章（VPN）・第22章（認証）の総仕上げです。落とし穴トップ3は、①デジタル署名は「送信者の秘密鍵で署名し、送信者の公開鍵で検証」で、機密性のための暗号化（受信者の公開鍵を使う）と鍵の向きが逆、②共通鍵方式で必要な鍵数はn(n−1)÷2、③IPsecのESPは暗号化＋認証・AHは認証のみ、です。FWや802.1Xは「誰が・どこで・何を判断するか」という登場人物の整理が決め手になります。仕上げたら午前Ⅱの過去問で定着させましょう。

### 確認問題

**問1.** 10人が互いに暗号通信を行うために、どの2人の間でも異なる鍵を使う共通鍵暗号方式を採用すると、必要な鍵の総数はいくつでしょう？

1. 10個
2. 20個
3. 45個
4. 90個

<details><summary>答えと解説</summary>

正解: **3**

必要な鍵数は2人の組合せの数、すなわちn(n−1)÷2＝10×9÷2＝45個です。10個は公開鍵暗号方式なら鍵ペアが人数分で済むという場合に相当する数で、90個はn(n−1)を2で割り忘れた値、20個は1人あたり2個と単純に数えた誤りです。

</details>

**問2.** デジタル署名の手順として、適切なものはどれでしょう？

1. 送信者が自分の秘密鍵でメッセージのハッシュ値に署名し、受信者は送信者の公開鍵で検証する
2. 送信者が受信者の公開鍵でメッセージ全体を暗号化して送る
3. 送信者と受信者があらかじめ共有した共通鍵でハッシュ値を保護する
4. 受信者が自分の秘密鍵で署名を作成して送信者へ返す

<details><summary>答えと解説</summary>

正解: **1**

署名は送信者の秘密鍵でしか作れないため、対応する公開鍵で検証できれば、本人が作成したことと改ざんがないことを確認できます。受信者の公開鍵で暗号化するのは機密性のための暗号化の手順、共有した共通鍵でハッシュ値を保護するのはメッセージ認証符号（MAC）の説明で、署名を作るのは受信者ではなく送信者です。

</details>

**問3.** PKIにおける認証局（CA）の役割として、適切なものはどれでしょう？

1. 通信データを暗号化して転送する
2. 公開鍵とその所有者の対応を保証するデジタル証明書を発行し、失効した証明書の情報を公開する
3. 利用者のパスワードを保管して代理入力する
4. すべての利用者に共通鍵を配布する

<details><summary>答えと解説</summary>

正解: **2**

CAは申請者を審査したうえで公開鍵証明書に署名して発行し、秘密鍵の漏えいなどで無効になった証明書をCRL（失効リスト）やOCSPで確認できるようにします。データの暗号化転送はTLSなど通信当事者側の処理で、パスワードの代理入力や共通鍵の一斉配布はCAの役割ではありません。

</details>

**問4.** 暗号学的ハッシュ関数に求められる性質として、適切なものはどれでしょう？

1. ハッシュ値から元のメッセージを復元できること
2. 入力の長さに比例した長さのハッシュ値を出力すること
3. 同じメッセージから毎回異なるハッシュ値が生成されること
4. 同じハッシュ値になる異なる2つのメッセージを見つけることが計算量的に困難であること

<details><summary>答えと解説</summary>

正解: **4**

衝突を見つけることが困難である性質（および、ハッシュ値から元のメッセージを求めることが困難な一方向性）が要件で、これにより改ざん検出やデジタル署名に使えます。ハッシュ関数は一方向なので復元できないことがむしろ要件であり、出力長は入力の長さによらず固定で、同じ入力からは常に同じ値が得られなければ照合に使えません。

</details>

**問5.** ステートフルインスペクション型ファイアウォールの説明として、適切なものはどれでしょう？

1. 通過を許可した通信のコネクション状態を記録し、その応答として戻ってくるパケットを動的に許可する
2. パケットを1つずつ独立に評価し、静的に設定された許可ルールだけで通過を判断する
3. 利用者に代わってアプリケーション層でコンテンツを中継する
4. 通過するファイルのウイルスを検知して駆除する

<details><summary>答えと解説</summary>

正解: **1**

ステートフルインスペクションはセッション管理テーブルで通信の状態を追跡し、内部から開始した通信の戻りパケットだけを自動的に許可するため、戻り方向の穴を静的に開けておく必要がありません。静的ルールのみで判定するのは単純なパケットフィルタリング、アプリケーション層での中継はプロキシ（アプリケーションゲートウェイ）、ウイルスの駆除はアンチウイルス製品の機能です。

</details>

**問6.** DMZの説明として、適切なものはどれでしょう？

1. 社内LANの中で最も機密性の高い情報を集めた区画
2. インターネットから一切アクセスできないように隔離したネットワーク
3. 外部に公開するサーバを置くために、インターネットと内部LANの双方からファイアウォールで分離した区画
4. 無線LAN端末だけを収容する専用のネットワーク

<details><summary>答えと解説</summary>

正解: **3**

DMZにはWebサーバやメール中継サーバなどの外部公開サーバを置き、万一サーバが侵害されても内部LANへ直接は到達できないようファイアウォールで分離します。外部からアクセスできなければ公開サーバの意味がなく、機密情報の区画や無線専用ネットワークという説明もDMZとは異なります。

</details>

**問7.** IPsecのESPをトンネルモードで使用した場合の動作として、適切なものはどれでしょう？

1. ペイロード部分のみを暗号化し、元のIPヘッダをそのまま使って転送する
2. パケットの認証のみを行い、暗号化はしない
3. 暗号化は行わず、カプセル化によるトンネルだけを作る

<details><summary>答えと解説</summary>

正解: **4**

トンネルモードのESPは元のIPヘッダを含むパケット全体を暗号化して保護し、VPN装置間の新しいIPヘッダを付けて転送するため、内部ネットワークのアドレス構成も隠せます。元のIPヘッダをそのまま使うのはトランスポートモード、認証のみで暗号化しないのはAHの説明で、暗号化を行わないトンネルはESPの説明として誤りです。

</details>

**問8.** TLSにおける暗号方式の使い分けとして、適切なものはどれでしょう？

1. すべての通信データを公開鍵暗号で暗号化する
2. 公開鍵暗号の技術でセッション用の共通鍵を安全に共有し、以降のデータは高速な共通鍵暗号で暗号化する
3. 共通鍵を平文のまま相手に送ってから暗号化を開始する
4. ハッシュ関数だけでデータの機密性を確保する

<details><summary>答えと解説</summary>

正解: **2**

公開鍵暗号は鍵配送の問題を解決できる一方で低速、共通鍵暗号は高速な一方で鍵配送が課題という特徴を組み合わせたハイブリッド方式です。全データを公開鍵暗号で処理するのは遅すぎて実用的でなく、共通鍵を平文で送れば盗聴されてしまい、ハッシュ関数には暗号化（機密性）の機能はありません。

</details>

**問9.** IEEE802.1Xの説明として、適切なものはどれでしょう？

1. 接続を許可する端末のMACアドレスを管理者が手動で登録しておく仕組み
2. Webページにパスワードを入力させて認証する方式
3. サプリカント（端末）・オーセンティケータ（スイッチや無線AP）・認証サーバで構成され、認証に成功するまでポートの一般通信を通さない仕組み
4. デジタル証明書を使わない簡易認証方式の総称

<details><summary>答えと解説</summary>

正解: **3**

802.1Xはポート単位のアクセス制御で、オーセンティケータが端末と認証サーバ（RADIUSなど）の間でEAPのやり取りを中継し、認証に成功するまで一般の通信を遮断します。MACアドレスの手動登録やWeb認証は別の方式であり、802.1XではEAP-TLSのようにデジタル証明書を使う認証方式も広く使われます。

</details>

**問10.** DNSキャッシュポイズニングの説明として、適切なものはどれでしょう？

1. 偽のDNS応答をキャッシュDNSサーバに記憶させ、その利用者を偽のサーバへ誘導する攻撃
2. DNSサーバへ大量の問い合わせを送り付けてサービスを停止させる攻撃
3. ゾーン転送の設定不備を悪用して内部のホスト情報を入手する行為
4. 正規のドメイン名に似せた別ドメインを取得して利用者をだます攻撃

<details><summary>答えと解説</summary>

正解: **1**

キャッシュポイズニングは、正規の応答より先に偽の応答を受け取らせてキャッシュを汚染し、以降その汚染されたキャッシュを参照する利用者を攻撃者のサーバへ誘導する攻撃です。大量の問い合わせによる停止はDoS攻撃、ゾーン転送の悪用は情報収集の手口、類似ドメインの取得はタイポスクワッティングなどの別の手口です。

</details>

## 4. 設計・運用ドリル

本編の第18章（無線LAN）・第23章（冗長化）・第24章（QoS）・第25章（クラウド・SDN）・第26章（運用管理）の総仕上げです。落とし穴トップ3は、①シェーピング（超過分をためて平滑化）とポリシング（超過分を廃棄）の混同、②SNMPのポーリング（マネージャから取得）とトラップ（エージェントから自発通知）の向き、③無線LANはCSMA/CAで、有線イーサネットのCSMA/CD（衝突検出）と区別する、です。帯域計算ではバイト→ビットの8倍を忘れないこと。ここまで終えたら午前Ⅱの過去問を回し始めましょう。

### 確認問題

**問1.** 負荷分散装置（ロードバランサ）のヘルスチェックの説明として、適切なものはどれでしょう？

1. サーバの負荷に応じて利用料金を計算する機能
2. サーバの応答を定期的に確認し、異常を検知したサーバを振り分け先から自動的に切り離す機能
3. 通過する通信からウイルスを検知して駆除する機能
4. 利用者のパスワードの強度を検査する機能

<details><summary>答えと解説</summary>

正解: **2**

ヘルスチェックはpingやHTTP応答の確認などでサーバの生死や正常性を定期的に確かめ、異常なサーバを振り分け対象から外すことでサービス全体を継続させる仕組みです。料金計算・ウイルス駆除・パスワード強度の検査は、いずれもロードバランサのヘルスチェックの機能ではありません。

</details>

**問2.** 契約帯域を超過したトラフィックに対する「シェーピング」の動作として、適切なものはどれでしょう？

1. 超過したパケットを直ちに廃棄する
2. 超過したパケットの優先度表示を書き換えるだけで、送出のタイミングは変えない
3. 超過しないように送信元のアプリケーションを強制停止させる
4. 超過したパケットをバッファにためて送出間隔を調整し、出力レートを一定以下に平準化する

<details><summary>答えと解説</summary>

正解: **4**

シェーピングはバッファリングによって出力レートを平準化する制御で、廃棄を抑えられる代わりに遅延が増えます。直ちに廃棄したり優先度の表示を書き換えたりするのはポリシングの動作です。送信元のアプリケーションを強制停止させる仕組みではありません。

</details>

**問3.** 100Mビット/秒の回線を使って50Mバイトのファイルを転送します。伝送効率が80％のとき、転送にかかる時間は何秒でしょう？

1. 4秒
2. 5秒
3. 0.5秒
4. 40秒

<details><summary>答えと解説</summary>

正解: **2**

50Mバイト＝50×8＝400Mビットです。実効速度は100×0.8＝80Mビット/秒なので、400÷80＝5秒かかります。4秒は伝送効率を考慮し忘れた値（400÷100）、0.5秒はバイトからビットへの8倍の換算を忘れた値（50÷100）、40秒は桁の換算を誤った値です。

</details>

**問4.** 無線LANのアクセス制御方式であるCSMA/CAの説明として、適切なものはどれでしょう？

1. 送信前に他局の電波がないことを確認し、さらにランダムな時間待ってから送信して衝突を避け、受信側からのACKで成功を確認する
2. 衝突を検出したら直ちに送信を中止し、ランダムな時間の後に再送する
3. 各端末に送信できる時間帯を順番に割り当てて衝突を完全に防ぐ
4. 衝突の発生を考慮せず、各端末が任意のタイミングで送信し続ける

<details><summary>答えと解説</summary>

正解: **1**

無線では自局の送信中に衝突を検出できないため、キャリアセンスとランダムな待ち時間（バックオフ）で衝突を回避し、ACKが返らなければ再送します。衝突を検出してから中止・再送するのは有線イーサネットのCSMA/CD、時間帯を順番に割り当てるのはTDMAなどの方式で、衝突を考慮しない送信ではスループットが大きく低下します。

</details>

**問5.** 無線LANのWPA2/WPA3におけるパーソナルモードとエンタープライズモードの違いとして、適切なものはどれでしょう？

1. パーソナルモードは通信の暗号化を行わない
2. エンタープライズモードは認証のみを行い、暗号化の機能を持たない
3. パーソナルモードは全端末で共有する事前共有鍵（パスフレーズ）で接続し、エンタープライズモードはIEEE802.1Xと認証サーバで利用者ごとに認証する
4. 両者に機能の違いはなく、名称だけが異なる

<details><summary>答えと解説</summary>

正解: **3**

パーソナルモード（PSK）は1つの事前共有鍵を全端末で共有するため、鍵が漏れると全体に影響します。エンタープライズモードは802.1XとRADIUSなどの認証サーバによって利用者・端末ごとに認証でき、企業での利用に適します。どちらのモードも通信の暗号化は行うので、暗号化しない・機能差がないという説明は誤りです。

</details>

**問6.** SNMPのトラップの説明として、適切なものはどれでしょう？

1. マネージャが定期的にエージェントへMIBの値を問い合わせる動作
2. エージェント同士が構成情報を同期し合う動作
3. マネージャがエージェントの設定値を書き換える動作
4. 障害などのイベントを契機に、エージェントがマネージャへ自発的に通知を送る動作

<details><summary>答えと解説</summary>

正解: **4**

トラップはエージェント側から送られる自発的な通知で、ポーリングの間隔を待たずに障害発生を知らせることができます。定期的な問い合わせはポーリング（GetRequestなど）、設定値の書き換えはSetRequestの動作で、エージェント同士が同期し合うという仕組みはSNMPにはありません。

</details>

**問7.** traceroute（tracert）が経路上のルータを特定する仕組みとして、適切なものはどれでしょう？

1. TTLを1から順に増やしたパケットを送り、各ルータが返すICMPの時間超過メッセージから経由ルータを近い順に特定する
2. 各ルータからSNMPで情報を読み出して経路を描画する
3. DNSのNSレコードを順にたどって経路を調べる
4. 各ルータのルーティングテーブルを直接取得して合成する

<details><summary>答えと解説</summary>

正解: **1**

TTL＝1のパケットは最初のルータで破棄されてICMP時間超過メッセージが返るため、TTLを1ずつ増やしながら送れば経由ルータを近い順に特定できます。SNMPやルーティングテーブルの取得には各機器へのアクセス権が必要でtracerouteの仕組みではなく、DNSのNSレコードは名前解決の委任情報であって通信経路とは無関係です。

</details>

**問8.** IaaSの説明として、適切なものはどれでしょう？

1. アプリケーションソフトウェアそのものをサービスとして提供する
2. アプリケーションの開発・実行環境までをサービスとして提供する
3. 仮想サーバやストレージ、ネットワークなどのITインフラを提供し、OSから上の層は利用者が管理する
4. 利用者のデータセンター内に専用の物理サーバを設置して貸し出す

<details><summary>答えと解説</summary>

正解: **3**

IaaSはCPU・メモリ・ストレージ・ネットワークといった基盤をサービスとして提供し、OS・ミドルウェア・アプリケーションは利用者側の管理範囲です。アプリケーションそのものの提供はSaaS、開発・実行環境までの提供はPaaSの説明で、利用者拠点への物理サーバ設置は共用基盤をオンデマンドで使うクラウドサービスの形態とは異なります。

</details>

**問9.** SDN（Software-Defined Networking）の特徴として、適切なものはどれでしょう？

1. ネットワーク機器そのものを完全に不要にする技術である
2. ネットワークの制御機能（コントロールプレーン）を転送機能から分離し、コントローラがソフトウェアで集中制御するアーキテクチャである
3. LANケーブルを無線通信に置き換えるための技術である
4. 各スイッチが自律的に判断する度合いを高める技術である

<details><summary>答えと解説</summary>

正解: **2**

SDNはOpenFlowに代表されるように、経路判断などの制御をコントローラへ集中させ、スイッチは指示に従って転送に専念する構成です。転送を担う機器自体は引き続き必要であり、無線化の技術でもありません。各機器の自律判断を高めるのではなく、集中制御によってネットワーク全体を柔軟に変更できるようにするのが特徴です。

</details>

**問10.** NTPの説明として、適切なものはどれでしょう？

1. ネットワーク上の機器の時刻をサーバに同期させるプロトコルで、複数機器のログを突き合わせる障害解析の前提になる
2. ネットワーク機器の構成ファイルを転送するためのプロトコル
3. 機器の死活をリアルタイムに監視するためのプロトコル
4. 回線の帯域使用量を測定するためのプロトコル

<details><summary>答えと解説</summary>

正解: **1**

NTPは階層（stratum）構造の時刻サーバに各機器の時計を同期させる仕組みで、複数機器のログを時系列で正しく突き合わせるために不可欠です。構成ファイルの転送はTFTPやFTPなど、死活監視はping（ICMP）やSNMP、帯域使用量の測定はSNMPのMIB値の取得などで行うもので、NTPの機能ではありません。

</details>
