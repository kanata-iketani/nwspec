# 第32章 午前Ⅰ模試（本試験形式30問）

本試験と同じ30問・同じ分野配分で挑む午前Ⅰの模試です。できれば時計で50分を計り、本番のつもりで一気に解いてみましょう。間違えた問題は該当する章（第2〜8章）に戻って復習します。

## 1. 午前Ⅰ模試・前半（問1〜15）

いよいよ午前Ⅰの模試です。本試験の午前Ⅰは**50分で30問**、つまり1問あたり**約100秒**しか使えません。このチャプターは前半の問1〜15に相当し、基礎理論・アルゴリズム・ハードウェアとOS・データベース・ネットワーク・セキュリティ・開発技術というテクノロジ系の問題を本試験と同じ配分で並べています。

### 時間配分の戦略

- 知識問題は**30秒前後で即断**します。迷ったら仮の答えを選んで先へ進みましょう
- **計算問題は後回し**が鉄則です。1問に3分かけて他が解けないのが最悪のパターンなので、まず全問に目を通し、即答できる問題から拾います
- 合格ラインは60点（30問中18問）です。満点を狙う試験ではないので、わからない問題があっても動揺しないことが大切です

前半15問を**25分以内**で抜けるのが理想のペースです。模試では「解けたか」だけでなく「ペースを守れたか」も振り返りましょう。

### 確認問題

**問1.** 16進数の 2A を10進数で表したものはどれでしょう？

1. 32
2. 42
3. 52
4. 170

<details><summary>答えと解説</summary>

正解: **2**

16進数は1桁が16を基数とするので、2A は 2×16＋10（A）＝42 です。32は16進数の20、52は16進数の34、170は16進数のAAに相当する値で、いずれも 2A の変換結果ではありません。基数変換は「桁の重み×数字」の合計で機械的に計算できます。

</details>

**問2.** 2つの入力が異なるときだけ1を出力する論理演算はどれでしょう？

1. AND（論理積）
2. OR（論理和）
3. XOR（排他的論理和）
4. NAND（否定論理積）

<details><summary>答えと解説</summary>

正解: **3**

XOR（排他的論理和）は入力が（0,1）または（1,0）のときだけ1を出力します。ANDは両方が1のときだけ1、ORはどちらか一方でも1なら1（両方1でも1）、NANDはANDの出力を反転したもので両方1のときだけ0になります。

</details>

**問3.** 整列済みの n 件のデータから2分探索で目的の値を探すときの計算量のオーダはどれでしょう？

1. O(1)
2. O(log n)
3. O(n)
4. O(n²)

<details><summary>答えと解説</summary>

正解: **2**

2分探索は1回の比較で探索範囲が半分になるため、比較回数は約 log₂n 回、つまり O(log n) です。1,000件でも約10回の比較で済みます。O(n) は先頭から順に調べる線形探索、O(n²) は単純な交換ソートなどのオーダで、O(1) はデータ件数に依存しない処理を指します。

</details>

**問4.** スタックに A、B、C の順でデータを格納（push）した後、1回取り出し（pop）を行ったとき、取り出されるデータはどれでしょう？

1. A
2. B
3. 取り出される順序は不定である
4. C

<details><summary>答えと解説</summary>

正解: **4**

スタックは後入れ先出し（LIFO）の構造なので、最後に入れた C が最初に取り出されます。A が最初に出るのは先入れ先出し（FIFO）であるキューの動作です。取り出し順はデータ構造の性質で一意に決まるため、不定ということはありません。

</details>

**問5.** キャッシュメモリの説明として、最も適切なものはどれでしょう？

1. CPUと主記憶の速度差を埋めるために、使用頻度の高いデータを格納する高速なメモリ
2. 電源を切っても内容が保持される補助記憶装置
3. 主記憶の容量不足を補うために補助記憶装置上に設ける領域
4. CPU内部で命令を解読して制御信号を作る装置

<details><summary>答えと解説</summary>

正解: **1**

キャッシュメモリはCPUと主記憶の間に置かれる高速・小容量のメモリで、両者の速度差を吸収して平均アクセス時間を短縮します。2つ目はSSDなどの補助記憶、3つ目は仮想記憶（スワップ領域）、4つ目は命令デコーダの説明で、いずれもキャッシュメモリではありません。

</details>

**問6.** 仮想記憶方式（ページング）に関する説明として、適切なものはどれでしょう？

1. 主記憶上のデータを定期的に補助記憶へバックアップする方式である
2. プログラム全体を常に主記憶へ置いてから実行する方式である
3. 主記憶の実容量より大きなアドレス空間をプログラムに提供できる
4. ページフォールトが多発するほど処理速度は向上する

<details><summary>答えと解説</summary>

正解: **3**

仮想記憶は、必要なページだけを主記憶に置き、残りを補助記憶に退避させることで、実容量より大きな論理アドレス空間を提供する仕組みです。プログラム全体を主記憶に置く必要はありません。ページフォールト（必要なページが主記憶にない状態）が多発するとスラッシングが起きて性能はむしろ低下します。バックアップの仕組みでもありません。

</details>

**問7.** 関係データベースの正規化を行う主な目的はどれでしょう？

1. データの重複をなくし、更新時の不整合を防ぐこと
2. 検索処理を必ず高速化すること
3. 表の数を減らして構造を単純にすること
4. データを暗号化して機密性を高めること

<details><summary>答えと解説</summary>

正解: **1**

正規化はデータの冗長性（重複）を排除し、挿入・更新・削除のときに矛盾が生じるのを防ぐための設計手法です。表は分割されるためむしろ数が増え、結合が必要になって検索が遅くなる場合もあるので「必ず高速化」は誤りです。暗号化とは無関係です。

</details>

**問8.** トランザクションのACID特性のうち、「処理がすべて実行されるか、まったく実行されないかのいずれかであることを保証する」性質はどれでしょう？

1. 一貫性（Consistency）
2. 原子性（Atomicity）
3. 独立性（Isolation）
4. 耐久性（Durability）

<details><summary>答えと解説</summary>

正解: **2**

全部実行か全部取消し（ロールバック）かを保証するのが原子性です。一貫性はデータの整合性制約が常に保たれること、独立性は同時に実行される複数のトランザクションが互いに干渉しないこと、耐久性はコミットした結果が障害後も失われないことを指します。

</details>

**問9.** OSI基本参照モデルにおいて、ルータが主に動作する層はどれでしょう？

1. 物理層
2. データリンク層
3. トランスポート層
4. ネットワーク層

<details><summary>答えと解説</summary>

正解: **4**

ルータはIPアドレスを見て転送先を決めるため、第3層のネットワーク層で動作します。リピータやハブは物理層、レイヤ2スイッチ（ブリッジ）はデータリンク層の機器です。トランスポート層はTCP/UDPが担う層で、通常のルータの転送判断には使いません。

</details>

**問10.** 100Mビット/秒の回線を使って50Mバイトのファイルを転送します。回線の伝送効率を80%とすると、転送に要する時間はおよそ何秒でしょう？

1. 0.5秒
2. 4秒
3. 5秒
4. 6.25秒

<details><summary>答えと解説</summary>

正解: **3**

まずファイルサイズをビットに直すと 50Mバイト×8＝400Mビット。実効速度は 100Mビット/秒×0.8＝80Mビット/秒なので、400÷80＝5秒です。0.5秒はバイトからビットへの換算漏れ（50÷100）、4秒は効率の掛け忘れ（400÷100）、6.25秒は効率を二重に適用した誤りです。

</details>

**問11.** 公開鍵暗号方式を使って、AさんがBさんへ機密性を確保してメッセージを送るとき、暗号化に使う鍵はどれでしょう？

1. Bさんの公開鍵
2. Bさんの秘密鍵
3. Aさんの公開鍵
4. Aさんの秘密鍵

<details><summary>答えと解説</summary>

正解: **1**

受信者Bだけが復号できるようにするには、Bの公開鍵で暗号化し、Bが自分だけが持つ秘密鍵で復号します。Bの秘密鍵はAが入手できないため暗号化には使えません。Aの公開鍵で暗号化するとBは復号できず、Aの秘密鍵で処理するのはディジタル署名の用途であり、機密性の確保にはなりません。

</details>

**問12.** ディジタル署名によって確認できることの組合せとして、適切なものはどれでしょう？

1. 通信経路の盗聴防止と可用性の向上
2. メッセージの機密性と転送速度の向上
3. 送信者の匿名性とメッセージの完全性
4. メッセージの改ざんの有無と送信者の真正性

<details><summary>答えと解説</summary>

正解: **4**

ディジタル署名は送信者の秘密鍵でメッセージのハッシュ値を暗号化したもので、検証により「改ざんされていないこと（完全性）」と「確かにその送信者が作成したこと（真正性・否認防止）」を確認できます。メッセージ本体の暗号化は行わないため機密性や盗聴防止にはならず、署名者を特定する仕組みなので匿名性とは逆の性質です。

</details>

**問13.** ランサムウェアの説明として、最も適切なものはどれでしょう？

1. キーボードの入力を記録してパスワードなどを盗むソフトウェア
2. データを暗号化して使用不能にし、復元と引換えに金銭を要求するソフトウェア
3. 自分自身を複製してネットワーク経由で自律的に感染を広げるソフトウェア
4. 有用なソフトウェアを装って侵入し、裏で遠隔操作の入口を作るソフトウェア

<details><summary>答えと解説</summary>

正解: **2**

ランサムウェア（ransom＝身代金）は、ファイルを暗号化するなどして使えなくし、復元と引換えに金銭を要求するマルウェアです。1つ目はキーロガー、3つ目はワーム、4つ目はバックドアを仕掛けるトロイの木馬の説明で、いずれもランサムウェアの定義とは異なります。

</details>

**問14.** ブラックボックステストの説明として、適切なものはどれでしょう？

1. プログラムの内部構造を考慮せず、入力と出力が仕様どおりかを確認するテスト
2. すべての分岐を少なくとも1回は実行するように設計するテスト
3. ソースコードを実行せずにレビューで欠陥を探す手法
4. 本番稼働後に利用者が業務で使いながら確認するテスト

<details><summary>答えと解説</summary>

正解: **1**

ブラックボックステストは内部ロジックを見ずに仕様（入出力の関係）に着目するテストで、同値分割や境界値分析でテストケースを設計します。分岐網羅は内部構造に着目するホワイトボックステストの基準、コードを実行しないレビューは静的テスト、利用者による確認は受入れテストや運用テストに近い説明です。

</details>

**問15.** スクラム開発において、1〜4週間程度の固定した期間で開発を繰り返す単位を何と呼ぶでしょう？

1. マイルストーン
2. プロトタイプ
3. スプリント
4. ベースライン

<details><summary>答えと解説</summary>

正解: **3**

スクラムでは固定期間の反復をスプリントと呼び、スプリントごとに動くソフトウェアを作って、ふりかえり（レトロスペクティブ）で改善します。マイルストーンは工程上の節目、プロトタイプは要求確認のための試作品、ベースラインは構成管理で基準とする時点の成果物を指す用語です。

</details>

## 2. 午前Ⅰ模試・後半（問16〜30）

後半の問16〜30です。本試験の午前Ⅰは**50分で30問**なので、前半を25分で抜けていれば残りは25分。ここからはテクノロジ系の残り（信頼性・性能の計算を含む）に加えて、**マネジメント系**（プロジェクトマネジメント・サービスマネジメント・監査）と**ストラテジ系**（経営戦略・会計・法務）が登場します。

### 後半の戦い方

- マネジメント系・ストラテジ系は計算がほぼなく、**用語の意味を知っていれば数十秒で解ける**問題が中心です。ここを素早く確実に拾うと、計算問題に回す時間が生まれます
- 稼働率や損益分岐点などの**計算問題は、式を思い出せないと感じたら印を付けて後回し**にします。最後に戻って、1問100秒の残り時間で落ち着いて計算しましょう
- 見直しの時間が余ったら、マークずれ（選択肢の取り違え）の確認を優先します

60点（18問）が合格ラインです。模試の結果から、分野ごとの正答率を出して弱点の章に戻りましょう。

### 確認問題

**問1.** 稼働率0.9の装置を2台並列に接続したシステム全体の稼働率はどれでしょう？（どちらか一方が稼働していればシステムは稼働とみなします）

1. 0.81
2. 0.90
3. 0.95
4. 0.99

<details><summary>答えと解説</summary>

正解: **4**

並列システムの稼働率は「両方が同時に故障している確率」を1から引いて求めます。1台が故障している確率は 1−0.9＝0.1 なので、2台とも故障する確率は 0.1×0.1＝0.01。よって稼働率は 1−0.01＝0.99 です。0.81は2台直列（0.9×0.9）の値、0.90は1台だけの稼働率で、0.95は根拠のない値です。

</details>

**問2.** MTBFが450時間、MTTRが50時間のシステムの稼働率はどれでしょう？

1. 0.80
2. 0.90
3. 0.95
4. 0.99

<details><summary>答えと解説</summary>

正解: **2**

稼働率は MTBF÷(MTBF＋MTTR)＝450÷(450＋50)＝450÷500＝0.9 です。MTBF（平均故障間動作時間）は動いていた時間の平均、MTTR（平均修復時間）は直すのにかかる時間の平均で、「全体の時間のうち動いていた割合」を求める式です。ほかの選択肢はこの式の計算結果と一致しません。

</details>

**問3.** RAID5の説明として、適切なものはどれでしょう？

1. データとパリティ情報を複数のディスクに分散して書き込み、1台の故障までデータを復元できる
2. 同じデータを2台のディスクに書き込むことで信頼性を高める
3. データを複数のディスクに分散して書き込むだけで、冗長性はない
4. パリティ専用のディスクを1台固定で設け、2台の故障まで復元できる

<details><summary>答えと解説</summary>

正解: **1**

RAID5はパリティを特定のディスクに固定せず全ディスクに分散して書き込み、1台が故障しても残りのデータとパリティから復元できます。2つ目はRAID1（ミラーリング）、3つ目はRAID0（ストライピング）の説明です。4つ目はパリティ専用ディスクを固定するRAID4と、2台故障に耐えるRAID6の特徴を混ぜた誤りです。

</details>

**問4.** システムの設計思想のうち、「故障が発生したとき、システムを安全な状態に移行させる」考え方はどれでしょう？

1. フールプルーフ
2. フェールソフト
3. フェールセーフ
4. フォールトアボイダンス

<details><summary>答えと解説</summary>

正解: **3**

フェールセーフは故障時に安全側へ倒す設計で、信号機が故障したら赤を表示して止める、といった例が典型です。フールプルーフは利用者の誤操作を防ぐ設計、フェールソフトは故障時に機能を縮退させてでも運転を続ける設計、フォールトアボイダンスは品質を高めてそもそも故障を起こしにくくする考え方です。

</details>

**問5.** クラウドサービスの分類のうち、OSやミドルウェアまでが事業者から提供され、利用者はその上で自分のアプリケーションを開発・実行するものはどれでしょう？

1. IaaS
2. PaaS
3. SaaS
4. DaaS

<details><summary>答えと解説</summary>

正解: **2**

PaaSはOS・ミドルウェアを含む実行基盤（プラットフォーム）まで事業者が提供し、利用者はアプリケーションの開発と運用に専念できます。IaaSは仮想サーバやネットワークなどの基盤のみ提供でOSから上は利用者が管理し、SaaSはアプリケーションそのものをサービスとして使う形態です。DaaSは仮想デスクトップ環境を提供するサービスを指します。

</details>

**問6.** プロジェクトマネジメントで用いるWBSの説明として、適切なものはどれでしょう？

1. プロジェクトの成果物や作業を階層的に分解して整理したもの
2. 作業の順序関係と所要日数を矢印で表した図
3. リスクの発生確率と影響度をまとめた一覧表
4. メンバーごとの稼働時間を月別に集計した表

<details><summary>答えと解説</summary>

正解: **1**

WBS（Work Breakdown Structure）は、成果物や作業をトップダウンに分解し、管理できる単位（ワークパッケージ）まで細分化して階層的に整理したものです。作業の順序と日数を矢印で表すのはアローダイアグラム（PERT図）で、クリティカルパスの計算に使います。リスクの一覧や稼働時間の集計表はWBSではありません。

</details>

**問7.** プロジェクトのリスク対応のうち、「損害保険に加入して損失発生時の負担を第三者に移す」行為はどれに分類されるでしょう？

1. 回避
2. 軽減
3. 受容
4. 転嫁

<details><summary>答えと解説</summary>

正解: **4**

保険への加入は、リスクが現実になったときの損失の負担を第三者（保険会社）に移す「転嫁」の典型例です。回避はリスクの原因となる活動自体をやめること、軽減は発生確率や影響度を下げる対策を打つこと、受容はあえて対策せずそのまま受け入れることを指します。

</details>

**問8.** ITサービスマネジメントにおけるインシデント管理の主な目的はどれでしょう？

1. 障害の根本原因を特定して恒久的な対策を行うこと
2. サービスへの変更を承認し、リリースを統制すること
3. 中断したサービスをできるだけ早く正常な状態に戻すこと
4. 将来の需要を予測して設備の容量を計画すること

<details><summary>答えと解説</summary>

正解: **3**

インシデント管理の目的は復旧の速さで、暫定対応（ワークアラウンド）でもよいのでまずサービスを利用できる状態に戻します。根本原因の追究と恒久対策は問題管理、変更の承認は変更管理、容量の計画はキャパシティ管理の役割で、インシデント管理とは目的が異なります。

</details>

**問9.** システム監査人に求められる立場として、最も適切なものはどれでしょう？

1. 監査対象の部門から独立した立場で、客観的に評価・助言する
2. 監査対象システムを開発した本人が、内容を最もよく知る者として自ら評価する
3. 被監査部門の管理者の指示に従って監査結果の結論を調整する
4. 発見した問題点は経営者に報告せず、現場だけで解決する

<details><summary>答えと解説</summary>

正解: **1**

システム監査人には外観上も精神上も独立性が求められ、監査対象から独立した立場で客観的に評価し、結果を監査の依頼者（経営者など）に報告します。開発した本人による評価は自己監査となって独立性を欠き、結論の調整や経営者への報告の省略は監査の信頼性そのものを損なうため不適切です。

</details>

**問10.** SWOT分析における「O（Opportunity）」が表すものはどれでしょう？

1. 自社の強み
2. 外部環境の機会
3. 自社の弱み
4. 外部環境の脅威

<details><summary>答えと解説</summary>

正解: **2**

SWOTは内部要因である強み（Strength）・弱み（Weakness）と、外部要因である機会（Opportunity）・脅威（Threat）を整理するフレームワークです。Oは市場の成長や規制緩和など、自社にとって追い風になる外部環境の変化を指します。強みと弱みは内部要因なのでOには当たらず、脅威はTが表します。

</details>

**問11.** コアコンピタンスの説明として、適切なものはどれでしょう？

1. 市場の隙間を狙い、小規模な市場で優位を築く戦略
2. 業務プロセスを抜本的に見直して再設計する手法
3. 他社が容易にまねできない、自社の中核となる強みや能力
4. 製品を低価格で大量に販売してシェアを獲得する戦略

<details><summary>答えと解説</summary>

正解: **3**

コアコンピタンスは、競合他社が模倣しにくい自社固有の技術やノウハウなど、競争優位の源泉となる中核的な能力のことです。1つ目はニッチ戦略、2つ目はBPR（ビジネスプロセスリエンジニアリング）、4つ目はコストリーダーシップ戦略に近い説明で、いずれもコアコンピタンスの定義ではありません。

</details>

**問12.** 情報システムの調達において、発注側が要件や条件を示し、ベンダーに具体的な提案を求めるために提示する文書はどれでしょう？

1. RFI
2. SLA
3. NDA
4. RFP

<details><summary>答えと解説</summary>

正解: **4**

RFP（提案依頼書）は、調達する範囲や要件、契約条件などを示してベンダーに提案書の提出を求める文書です。RFI（情報提供依頼書）はその前段階で製品や技術の情報を広く集めるためのもの、SLAはサービス水準に関する合意、NDAは秘密保持契約で、いずれも提案を求める文書ではありません。

</details>

**問13.** 固定費が600万円、変動費率が0.6（売上高の60%）の事業における損益分岐点売上高はどれでしょう？

1. 960万円
2. 1,000万円
3. 1,500万円
4. 3,600万円

<details><summary>答えと解説</summary>

正解: **3**

損益分岐点売上高＝固定費÷(1−変動費率)＝600万円÷(1−0.6)＝600万円÷0.4＝1,500万円です。売上高の40%（限界利益）で固定費600万円をちょうど賄える点を求めています。1,000万円は600÷0.6と式を取り違えた値、960万円や3,600万円も式の立て方を誤った計算結果です。

</details>

**問14.** 法人の従業員が職務上作成したプログラムの著作権について、著作権法上の原則として適切なものはどれでしょう？

1. 契約や勤務規則に別段の定めがなければ、法人が著作者となる
2. 常に作成した従業員個人に帰属する
3. プログラムに著作権は発生せず、特許権としてのみ保護される
4. 所定の機関に登録しなければ著作権は発生しない

<details><summary>答えと解説</summary>

正解: **1**

法人の発意に基づいて従業員が職務上作成するプログラムの著作物は、別段の定めがない限り法人が著作者となります（職務著作）。したがって個人帰属が原則というのは誤りです。プログラムは著作物として保護され（特許権とは別の制度）、著作権は創作した時点で自動的に発生するため登録は不要です。

</details>

**問15.** 不正アクセス禁止法で禁止される行為に該当するものはどれでしょう？

1. 自分のパスワードを長期間変更せずに使い続ける行為
2. 他人のIDとパスワードを無断で入力し、ネットワーク経由でサーバにログインする行為
3. 社内規程に違反して業務時間中に私的なWebサイトを閲覧する行為
4. 利用許諾の範囲内でフリーソフトウェアを業務に利用する行為

<details><summary>答えと解説</summary>

正解: **2**

他人の識別符号（IDとパスワード）を無断で入力してアクセス制御を突破する行為は、不正アクセス禁止法が禁止する不正アクセス行為の典型です。パスワードを変更しないことや私的なWeb閲覧は社内規律や運用の問題であって同法の処罰対象ではなく、許諾の範囲内でのソフトウェア利用は適法な行為です。

</details>
