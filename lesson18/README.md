# 第18章 無線LAN

ケーブルのない通信=無線LAN の章です。規格と周波数帯のきほんから、AP の配置設計、WPA2/WPA3 のセキュリティ、干渉や隠れ端末といったトラブルまでを扱います。

## 1. 無線LAN のきほん（IEEE802.11・周波数帯・チャネル）

無線LAN（Wi-Fi）は、ケーブルの代わりに**電波**でデータをやり取りする LAN です。規格は **IEEE802.11** シリーズとして標準化されています。

### 主な規格と周波数帯

| 規格 | 通称 | 周波数帯 |
|---|---|---|
| 802.11n | Wi-Fi 4 | 2.4GHz / 5GHz |
| 802.11ac | Wi-Fi 5 | 5GHz |
| 802.11ax | Wi-Fi 6 / 6E | 2.4GHz / 5GHz（6E は 6GHz も） |

### 周波数帯の性格の違い

- **2.4GHz 帯**: 電波が遠くまで届き、障害物にも比較的強い。ただし電子レンジや Bluetooth も使う帯域なので**干渉が多い**。チャネル同士が重なっており、互いに重ならないのは実質 **1・6・11 の3つ**程度
- **5GHz 帯**: チャネル数が多く干渉に強いが、2.4GHz より**距離・障害物に弱い**。一部チャネルは気象レーダ等と共用のため、レーダを検知すると自動でチャネルを変える **DFS** 機能が必要
- **6GHz 帯**: Wi-Fi 6E 以降で使える新しい帯域。広くて空いている

### アクセス制御は CSMA/CA

無線は「送信しながら衝突を検知する」ことができないため、有線の CSMA/CD ではなく **CSMA/CA（衝突回避）**を使います。送信前に電波が空いているかを確認し、ランダムな待ち時間を置いてから送信、受信側は **ACK** で受領を知らせます。

🔴 「2.4GHz=遠くまで届くが干渉が多い」「5GHz=チャネルが多いが距離に弱い」の対比と CSMA/CA は確実に押さえましょう。

### 確認問題

**問1.** 2.4GHz 帯の無線LAN の特徴として、適切なものはどれでしょう？

1. 電子レンジなどの影響を受けず、干渉が起きない
2. 5GHz 帯より電波が遠くまで届きやすいが、他機器との干渉が起きやすい
3. 気象レーダとの共用のため DFS が必須である
4. Wi-Fi 6E で初めて利用可能になった帯域である

<details><summary>答えと解説</summary>

正解: **2**

2.4GHz 帯は波長が長く障害物を回り込みやすいため到達距離に優れる一方、電子レンジや Bluetooth と帯域を共有するため干渉が多いのが弱点です。DFS が関係するのは 5GHz 帯の一部チャネル、Wi-Fi 6E で追加されたのは 6GHz 帯です。

</details>

**問2.** 2.4GHz 帯で複数の AP を設置するとき、互いに干渉しないチャネルの組み合わせとして代表的なものはどれでしょう？

1. 1・2・3
2. すべてのチャネルを同じ番号に揃える
3. 1・6・11
4. チャネルは干渉と無関係なので任意でよい

<details><summary>答えと解説</summary>

正解: **3**

2.4GHz 帯は隣り合うチャネルの周波数が重なっているため、十分に離れた 1・6・11 の組み合わせが干渉を避ける定番です。1・2・3 は帯域が重なって干渉し、全 AP を同じチャネルにすると電波の取り合いが発生します。チャネル設計は無線の品質を左右する重要な要素です。

</details>

**問3.** 無線LAN で CSMA/CA が使われる理由として、適切なものはどれでしょう？

1. 無線では送信しながら衝突を検知することが難しいため、送信前の確認と待ち時間で衝突を回避する
2. 無線は有線より帯域が広く、衝突がそもそも発生しないため
3. トークンを持つ端末だけが送信できる方式だから
4. AP がすべての端末の送信タイミングを事前に予約するから

<details><summary>答えと解説</summary>

正解: **1**

無線では自分の送信電波が強すぎて他局の電波を同時に聞けず、衝突検知（CD）ができません。そこで送信前にキャリアを確認し、ランダム待ち時間と ACK で衝突を回避する CSMA/CA を使います。無線でも衝突は発生します。トークン方式はトークンリングの仕組みで、CSMA/CA は事前予約型のアクセス制御でもありません。

</details>

**問4.** 5GHz 帯の一部チャネルで必要となる DFS 機能の説明として、適切なものはどれでしょう？

1. 電波の暗号化方式を自動的に強化する機能
2. SSID を自動的に隠す機能
3. 電波の出力を常に最大化する機能
4. 気象レーダなどの電波を検知すると、自動的に別のチャネルへ移動する機能

<details><summary>答えと解説</summary>

正解: **4**

5GHz 帯の一部は気象レーダなどと周波数を共用しているため、レーダ波を検知したら自動でチャネルを変更する DFS が義務付けられています。暗号化の強化や SSID の秘匿、出力の調整は DFS とは別の機能です。DFS の動作中は一時的に通信が切り替わる点も設計時の考慮事項になります。

</details>

## 2. SSID とローミング・AP の配置設計

### SSID はネットワークの「名前」

無線LAN に接続するとき一覧に出てくる名前が **SSID** です。端末は SSID を選び、認証に成功すると **AP（アクセスポイント）**に接続（アソシエーション）します。

### ローミング: AP をまたいで移動する

オフィスのように広い場所では AP を複数台設置します。このとき**すべての AP に同じ SSID と同じセキュリティ設定**をしておくと、端末は移動中に電波の強い AP へ自動的に接続を切り替えます。これが**ローミング**です。携帯電話が基地局を渡り歩くのと同じイメージです。

> 💡 コツ: ローミングの主導権は**端末側**にあります。どのタイミングでどの AP に切り替えるかは基本的に端末が判断します。

### AP 配置設計のポイント

- **セル（電波の届く範囲）を少し重ねる**: すき間があるとローミング時に通信が途切れる。ただし重ねすぎると干渉する
- **隣り合う AP は別チャネルにする**: 同じチャネルだと電波の取り合い（干渉）が起きる。2.4GHz なら 1・6・11 を市松模様のように配置する
- **電波出力の調整**: 強すぎると遠くの AP 同士が干渉し、端末がいつまでも遠い AP につかみ続ける原因にもなる
- **現地調査（サイトサーベイ）**: 壁や什器による減衰は図面だけでは分からないため、実際に電波を測定して配置を決める

🟡 「同じ SSID・同じセキュリティ設定でローミング」「隣接 AP は別チャネル」が設計問題の定石です。

### 確認問題

**問1.** 複数の AP の間を端末が移動しても通信を継続できるようにする（ローミングさせる）ための基本的な設定はどれでしょう？

1. AP ごとに異なる SSID を設定する
2. すべての AP に同じ SSID と同じセキュリティ設定をする
3. すべての AP を同じチャネルに設定する
4. 端末の IP アドレスを AP ごとに手動で変更する

<details><summary>答えと解説</summary>

正解: **2**

ローミングには、端末から見て「同じネットワーク」に見えるよう全 AP に同一の SSID とセキュリティ設定を施すことが基本です。SSID が異なると端末は別ネットワークと認識し自動では切り替わりません。チャネルはむしろ隣接 AP 同士で変えて干渉を防ぎます。IP アドレスの手動変更は不要で、同一セグメントなら維持されます。

</details>

**問2.** 隣り合う AP のチャネルを変えて配置する主な目的はどれでしょう？

1. セキュリティを強化して盗聴を防ぐため
2. 端末の消費電力を減らすため
3. AP 同士の電波干渉を避け、通信品質を保つため
4. SSID を自動的に統一するため

<details><summary>答えと解説</summary>

正解: **3**

同じチャネルの AP が近くにあると電波の取り合い（同一チャネル干渉）が発生し、スループットが低下します。隣接 AP のチャネルをずらすのはこの干渉を避けるためです。チャネル設計は暗号化とは無関係なので盗聴対策にはならず、消費電力の削減や SSID の統一とも関係ありません。

</details>

**問3.** AP の電波の届く範囲（セル）の設計として、適切な考え方はどれでしょう？

1. セルは完全に分離し、重なりをゼロにする
2. すべての AP の出力を常に最大にする
3. セルの形は図面上の計算だけで確定でき、現地測定は不要である
4. 隣のセルと適度に重ねて、移動時に通信が途切れないようにする

<details><summary>答えと解説</summary>

正解: **4**

セルにすき間があるとローミング時に圏外が生じるため、隣接セルは適度に重ねます。完全に分離するとその境目で通信が切れます。出力を最大にすると遠くの AP 同士の干渉や、端末が遠い AP をつかみ続ける問題を招きます。壁や什器の減衰は図面では正確に分からないため、サイトサーベイ（現地調査）が重要です。

</details>

**問4.** 無線LAN のローミングにおいて、接続先 AP を切り替える判断を基本的に行うのはどれでしょう？

1. 端末（クライアント）
2. DNS サーバ
3. DHCP サーバ
4. ルータ

<details><summary>答えと解説</summary>

正解: **1**

どの AP に接続するか、いつ切り替えるかの判断は基本的に端末側が電波強度などを基に行います。ルータは経路制御、DHCP は IP アドレスの配布、DNS は名前解決の役割であり、ローミングの切り替え判断は行いません。端末任せであるがゆえに、切り替えが遅い端末への対策が設計上の論点になることもあります。

</details>

## 3. 無線LAN のセキュリティ（WPA2/WPA3・PSK とエンタープライズ)

無線は電波が壁を越えて飛ぶため、**建物の外からでも傍受できる**可能性があります。だからこそ暗号化と認証が必須です。

### 暗号化方式の変遷

| 方式 | 状態 |
|---|---|
| WEP | **解読可能。使用禁止レベル** |
| WPA2 | AES ベース(CCMP)。現在も広く利用 |
| WPA3 | 最新。**SAE** という鍵交換でパスワード推測攻撃に強い |

WPA2-PSK には、パスフレーズが漏れると過去の通信も解読されうる、オフラインでのパスワード総当たりに弱いといった弱点があり、WPA3 の **SAE（同時認証）**はこれを改善しています。

### PSK とエンタープライズの違い

- **パーソナル（PSK）**: 全員が**同じ事前共有鍵（パスフレーズ）**を使う。家庭や小規模向け。退職者が出ても鍵を変えにくいのが弱点
- **エンタープライズ**: **IEEE802.1X + RADIUS サーバ**で利用者を**1人ずつ認証**（ID/パスワードや証明書）。企業向け。個人単位で利用停止でき、通信の鍵も端末ごとに別になる

> 💡 コツ: 「PSK=合言葉をみんなで共有」「エンタープライズ=1人ずつ身分証で入館」とイメージすると区別できます。

### 気休めにしかならない対策

**SSID ステルス**（SSID を見えなくする）や **MAC アドレスフィルタリング**は、ツールを使えば簡単に回避できるため、暗号化の代わりにはなりません。

🔴 WPA3=SAE、エンタープライズ=802.1X+RADIUS の対応は午前Ⅱ頻出です。

### 確認問題

**問1.** WPA3 で導入された SAE の効果として、適切なものはどれでしょう？

1. SSID を完全に秘匿できる
2. 電波の到達距離が2倍になる
3. MAC アドレスの偽装を物理的に不可能にする
4. パスフレーズに対するオフラインでの総当たり攻撃に強くなる

<details><summary>答えと解説</summary>

正解: **4**

SAE は鍵交換のたびに対話的なやり取りを必要とするため、キャプチャしたデータだけを使ったオフラインのパスワード総当たり攻撃が困難になります。SSID の秘匿や電波の到達距離は暗号方式とは無関係です。MAC アドレスの偽装防止も SAE の機能ではありません。

</details>

**問2.** WPA2-PSK（パーソナル）と比較した WPA2/WPA3 エンタープライズの特徴として、適切なものはどれでしょう？

1. 802.1X と RADIUS サーバを使い、利用者を個別に認証できる
2. 全員が同じパスフレーズを共有するため管理が簡単である
3. 暗号化を行わないため高速である
4. 認証サーバが不要になる

<details><summary>答えと解説</summary>

正解: **1**

エンタープライズモードは 802.1X と RADIUS サーバによる個別認証を行い、退職者のアカウントだけを無効化するといった運用が可能です。全員で同じパスフレーズを共有するのは PSK（パーソナル）の方式です。暗号化は当然行われ、むしろ認証サーバ（RADIUS）が必須になります。

</details>

**問3.** 無線LAN のセキュリティ対策のうち、単独では防御効果が低く「暗号化の代わりにならない」とされるものはどれでしょう？

1. WPA3 による暗号化
2. SSID ステルスと MAC アドレスフィルタリング
3. 802.1X によるユーザ認証
4. AES(CCMP) による暗号化

<details><summary>答えと解説</summary>

正解: **2**

SSID ステルスは電波を観測すれば SSID が判明し、MAC アドレスは容易に偽装できるため、どちらも回避が簡単で本質的な防御になりません。WPA3 や AES(CCMP) による暗号化、802.1X による認証は現在推奨される有効な対策です。

</details>

**問4.** 社内の無線LAN で「退職した社員が以前の設定のまま接続できてしまう」リスクを最も効果的に減らせる構成はどれでしょう？

1. SSID を定期的に変更する PSK 運用
2. MAC アドレスフィルタリングのみの運用
3. 802.1X+RADIUS による個別認証（エンタープライズ）でアカウントを無効化する運用
4. WEP による暗号化と長いパスフレーズの組み合わせ

<details><summary>答えと解説</summary>

正解: **3**

エンタープライズ認証なら、退職者のアカウントを RADIUS 側で無効化するだけで接続を止められます。PSK は全員共通の鍵なので、確実にやるには全端末の鍵を変更する必要があり運用負荷が高くなります。MAC アドレスは偽装可能で、WEP は解読可能な方式なのでパスフレーズを長くしても安全になりません。

</details>

## 4. 無線のトラブル（干渉・隠れ端末・電波強度）

「つながるけど遅い」「時々切れる」——無線LAN のトラブルは原因の切り分けが大切です。代表的な3つを押さえましょう。

### 1. 電波干渉

- **同一チャネル干渉**: 近くの AP（隣のフロアや隣のオフィスも含む）が同じチャネルを使うと、電波の順番待ちが増えて遅くなる
- **他機器からの干渉**: 2.4GHz 帯は電子レンジ・Bluetooth などとも帯域を共有している。「昼休みだけ遅くなる」なら電子レンジを疑うのが定石
- 対策: チャネルの変更、5GHz 帯への移行、干渉源の特定

### 2. 隠れ端末問題

端末 A と端末 C が、どちらも AP には届くが**互いの電波は届かない**位置にいるとします。A は「C が送信中」と気づけないため、同時に送信して AP 側で衝突が起きます。これが**隠れ端末問題**です。

対策は **RTS/CTS**: 送信前に端末が AP へ「送っていい？（RTS）」と聞き、AP が「どうぞ、他は待って（CTS）」と**全端末に聞こえる形で**返すことで、互いに見えない端末同士の衝突を防ぎます。

### 3. 電波強度

受信強度は **dBm** で表し、**0 に近いほど強い**です（例: -50dBm は強い、-85dBm は弱い）。壁・金属・水槽などで電波は減衰します。強度が足りない場所には AP の増設や配置変更で対応します。

🟡 隠れ端末問題と RTS/CTS の組み合わせは午前Ⅱの定番です。

### 確認問題

**問1.** 無線LAN の「隠れ端末問題」の説明として、適切なものはどれでしょう？

1. SSID をステルス化した AP に端末が接続できなくなる問題
2. 互いの電波が届かない端末同士が同時に送信し、AP 側で衝突が発生する問題
3. 端末の MAC アドレスが他の端末と重複する問題
4. AP の管理画面が外部から見えてしまう問題

<details><summary>答えと解説</summary>

正解: **2**

隠れ端末問題は、AP には届くが端末同士は互いの電波を検知できない位置関係のとき、キャリアセンスが機能せず同時送信による衝突が起きる現象です。SSID ステルスや MAC アドレスの重複、管理画面の公開は別の問題であり、隠れ端末問題とは関係ありません。

</details>

**問2.** 隠れ端末問題への対策として使われる仕組みはどれでしょう？

1. DFS によるチャネル自動変更
2. SSID の変更
3. WPA3 への移行
4. RTS/CTS による送信前の予約

<details><summary>答えと解説</summary>

正解: **4**

RTS/CTS は、送信したい端末が RTS を送り、AP が全端末に聞こえる CTS で許可を返すことで、互いに見えない端末の送信を抑制し衝突を防ぎます。DFS はレーダ波の回避、SSID の変更は干渉や衝突とは無関係、WPA3 はセキュリティの強化であって衝突対策ではありません。

</details>

**問3.** 「オフィスで昼休みの時間帯だけ 2.4GHz 帯の無線LAN が極端に遅くなる」場合、まず疑うべき原因はどれでしょう？

1. 電子レンジなど 2.4GHz 帯を使う機器からの電波干渉
2. DNS サーバの故障
3. サーバ証明書の期限切れ
4. IP アドレスの重複

<details><summary>答えと解説</summary>

正解: **1**

電子レンジは 2.4GHz 帯の強い電波ノイズ源で、昼休みという使用時間と症状の時間帯が一致する典型例です。DNS 故障なら名前解決が常時失敗し、証明書の期限切れは特定サイトのエラーとして現れます。IP アドレスの重複も時間帯とは無関係に発生します。症状の「時間帯の規則性」は切り分けの大きなヒントです。

</details>

**問4.** 無線LAN の受信電波強度の見方として、適切なものはどれでしょう？

1. -85dBm は -50dBm より強い電波である
2. dBm の値は距離に関係なく一定である
3. dBm は 0 に近いほど強く、-50dBm は -85dBm より強い電波である
4. 電波強度は壁や障害物の影響を受けない

正解: **3**

受信強度の dBm はマイナスの値で表され、0 に近いほど強い信号です。したがって -50dBm の方が -85dBm より強くなります。電波は距離とともに弱まり、壁や金属などの障害物でも減衰するため、「一定」「影響を受けない」という選択肢は誤りです。
