# 第30章 午前Ⅰドリル

第2〜8章で学んだ午前Ⅰの範囲を、4つの分野別ドリル（計40問）で総仕上げする章です。ここで間違えた問題は本編の該当章に戻って穴をふさぎ、仕上げは手持ちの午前Ⅰ過去問で行いましょう。

## 1. 基礎理論・アルゴリズムドリル

午前Ⅰの基礎理論・アルゴリズムは、本編の第2章（2進数・論理・CPU・メモリ）と第3章（アルゴリズム）の総仕上げです。落とし穴トップ3は、①負数は「2の補数」＝ビット反転して1を加える（反転だけで止めない）、②シフト演算は左へnビットで2のn乗倍（右シフトと取り違えない）、③スタックはLIFO・キューはFIFOの取り違え、です。2分探索が「整列済み限定」であることや、整列アルゴリズムと計算量の対応も頻出です。間違えた問題は第2・3章に戻って確認してから、手持ちの過去問に進みましょう。

### 確認問題

**問1.** 10進数の13を2進数で表したものはどれでしょう？

1. 1011
2. 1101
3. 1110
4. 1001

<details><summary>答えと解説</summary>

正解: **2**

13は8＋4＋1に分解できるので、8・4・2・1の重みに当てはめると1101です。1011は11、1110は14、1001は9を表します。重みの表を書いて大きい方から引いていくと確実です。

</details>

**問2.** 8ビットの2の補数表現で、−6を表すビット列はどれでしょう？

1. 00000110
2. 11111001
3. 11111010
4. 10000110

<details><summary>答えと解説</summary>

正解: **3**

6＝00000110の全ビットを反転した11111001に1を加えた11111010が−6です。00000110は＋6そのもの、11111001は反転しただけの1の補数、10000110は符号ビットを立てただけで2の補数表現ではありません。

</details>

**問3.** 論理変数A、Bについて、論理式 A AND (A OR B) を簡単にしたものはどれでしょう？

1. A
2. B
3. A OR B
4. A AND B

<details><summary>答えと解説</summary>

正解: **1**

吸収律により A AND (A OR B)＝A です。Aが1なら全体は必ず1、Aが0なら全体は必ず0になり、Bの値に関係なくAと一致します。B、A OR B、A AND B はいずれもBの値によって元の式と食い違う場合があります。

</details>

**問4.** 正の2進整数を、あふれが生じない範囲で左へ2ビット論理シフトすると、元の値の何倍になるでしょう？

1. 2倍
2. 4倍
3. 8倍
4. 4分の1倍

<details><summary>答えと解説</summary>

正解: **2**

左へ1ビットシフトするごとに2倍になるので、2ビットでは2の2乗＝4倍です。2倍は1ビット、8倍は3ビットシフトした場合で、4分の1倍は逆に右へ2ビットシフトしたときの値です。

</details>

**問5.** 空のスタックに対して push(a)、push(b)、pop、push(c)、pop、pop の順に操作したとき、popで取り出されるデータの順序はどれでしょう？

1. a、b、c
2. c、b、a
3. b、a、c
4. b、c、a

<details><summary>答えと解説</summary>

正解: **4**

スタックは後入れ先出し（LIFO）です。1回目のpopでは直前に積んだb、2回目では直前に積んだc、最後に底に残ったaが取り出されます。a、b、cは先入れ先出し（キュー）の動きで、c、b、aやb、a、cは途中にpopが挟まる流れを見落とした順序です。

</details>

**問6.** 2分探索法の説明として、適切なものはどれでしょう？

1. 整列済みのデータを対象に、中央の要素と比較して探索範囲を半分ずつに絞り込む
2. データの先頭から順に1件ずつ比較していく
3. データのハッシュ値から格納位置を直接計算して探す
4. 整列されていないデータに対しても、そのまま適用できる

<details><summary>答えと解説</summary>

正解: **1**

2分探索は整列済みであることが前提で、中央値との大小比較で範囲を半分にしていくため、計算量はO(log n)です。先頭から順に比較するのは線形探索、ハッシュ値で位置を直接求めるのはハッシュ探索の説明で、未整列のデータには2分探索は適用できません。

</details>

**問7.** 要素数nの配列を隣接交換法（バブルソート）で整列するときの平均計算量はどれでしょう？

1. O(n)
2. O(log n)
3. O(n^2)
4. O(n log n)

<details><summary>答えと解説</summary>

正解: **3**

バブルソートは隣り合う要素の比較・交換を繰り返すため、比較回数はおよそnの2乗に比例し、O(n^2)です。O(n log n)はクイックソートやマージソートの平均計算量、O(n)は線形探索など、O(log n)は2分探索の計算量です。

</details>

**問8.** 基準値（ピボット）を選び、それより小さいグループと大きいグループにデータを分割する操作を再帰的に繰り返す整列アルゴリズムはどれでしょう？

1. マージソート
2. ヒープソート
3. 挿入ソート
4. クイックソート

<details><summary>答えと解説</summary>

正解: **4**

基準値による分割を繰り返すのはクイックソートです。マージソートは細かく分割した後に併合（マージ）しながら整列し、ヒープソートはヒープ構造から最大値（または最小値）を順に取り出し、挿入ソートは整列済みの部分に1件ずつ正しい位置で挿入していく方式です。

</details>

**問9.** 先に入れたデータから順に取り出す「先入れ先出し（FIFO）」のデータ構造はどれでしょう？

1. スタック
2. キュー
3. 2分木
4. ハッシュ表

<details><summary>答えと解説</summary>

正解: **2**

FIFOはキューで、プリンタの印刷待ちのように到着順に処理したい場面で使われます。スタックは後入れ先出し（LIFO）、2分木はデータを階層的に保持する構造、ハッシュ表はキーから格納位置を計算する構造で、いずれも到着順に取り出す構造ではありません。

</details>

**問10.** 16進数の2Aを10進数で表した値はどれでしょう？

1. 42
2. 32
3. 44
4. 26

<details><summary>答えと解説</summary>

正解: **1**

16進数2Aは、2×16＋10＝42です（Aは10進数の10）。32は上位桁の2×16だけを計算してAを足し忘れた値、44はAを12と誤読した場合の値、26は16進数1A（16＋10）を変換した値です。

</details>

## 2. ハードウェア・OS・DBドリル

本編の第2章（メモリ階層）・第4章（OS・システム構成）・第5章（データベース）の総仕上げです。落とし穴トップ3は、①実効アクセス時間は「ヒット率×キャッシュ＋(1−ヒット率)×主記憶」の加重平均で計算する、②WHEREは行の絞り込み・HAVINGはグループ化後の絞り込みという適用順序、③ロールバック（更新前ログで取り消す）とロールフォワード（更新後ログで再現する）の向きの混同、です。デッドロックの対策や、内部割込みと外部割込みの分類も整理してから過去問へ進みましょう。

### 確認問題

**問1.** キャッシュメモリを設ける目的として、適切なものはどれでしょう？

1. 主記憶の容量を見かけ上大きくする
2. 停電時にもデータを保持する
3. CPUと主記憶の速度差を埋めて、実効的なアクセス時間を短縮する
4. 磁気ディスクの故障に備えて複製を保持する

<details><summary>答えと解説</summary>

正解: **3**

キャッシュメモリは高速・小容量のメモリに使用頻度の高いデータを置き、CPUから見た平均アクセス時間を短縮します。容量を見かけ上大きくするのは仮想記憶、停電時のデータ保持は不揮発性メモリ、複製による故障対策はRAIDなどの役割です。

</details>

**問2.** キャッシュメモリのアクセス時間が10ナノ秒、主記憶のアクセス時間が60ナノ秒、ヒット率が80％のとき、実効アクセス時間は何ナノ秒でしょう？

1. 20ナノ秒
2. 12ナノ秒
3. 35ナノ秒
4. 50ナノ秒

<details><summary>答えと解説</summary>

正解: **1**

実効アクセス時間＝0.8×10＋0.2×60＝8＋12＝20ナノ秒です。ヒットした場合とミスした場合を確率で重み付けして合計します。12ナノ秒はミス分の0.2×60だけ、35ナノ秒は単純平均(10＋60)÷2、50ナノ秒はヒット率を逆にして0.2×10＋0.8×60とした誤りです。

</details>

**問3.** 仮想記憶におけるスラッシングの説明として、適切なものはどれでしょう？

1. 必要なページが主記憶に存在しないときに発生する割込みのこと
2. 主記憶の空き領域が細切れになり、連続した領域を確保できなくなる現象
3. キャッシュメモリの内容と主記憶の内容が食い違う現象
4. ページの入れ替えが多発し、置き換え処理に時間を取られて処理性能が急激に低下する現象

<details><summary>答えと解説</summary>

正解: **4**

スラッシングは主記憶の不足などでページインとページアウトが頻発し、本来の処理がほとんど進まなくなる現象です。必要なページがないときの割込みはページフォールト、空き領域の細切れはフラグメンテーション、キャッシュと主記憶の食い違いは一貫性（コヒーレンシ）の問題の説明です。

</details>

**問4.** デッドロックの防止策として、適切なものはどれでしょう？

1. すべてのタスクの優先度を同じにする
2. すべてのタスクが資源を同じ順序で確保するようにする
3. ロックをかける単位をできるだけ小さくする
4. トランザクションのコミットを禁止する

<details><summary>答えと解説</summary>

正解: **2**

デッドロックは複数のタスクが互いに相手の確保した資源の解放を待ち合う状態で、資源の確保順序を全タスクで統一すれば待ちの循環が発生しなくなります。優先度の統一は待ち合いと無関係で、ロック単位を小さくしても確保順序が異なれば防げず、コミットの禁止では処理自体が成立しません。

</details>

**問5.** 関係データベースの正規化を行う主な目的はどれでしょう？

1. データの重複を排除して、更新時の矛盾（更新時異状）を防ぐ
2. 検索処理を必ず高速化する
3. データを暗号化して機密性を高める
4. 表の数を減らして構造を単純にする

<details><summary>答えと解説</summary>

正解: **1**

正規化は同じデータを複数の場所に重複して持たないように表を分割し、更新漏れによる矛盾を防ぐ設計手法です。表の分割によって結合が増え、検索はむしろ遅くなる場合もあります。暗号化は正規化とは別の仕組みで、正規化を進めると表の数は普通は増えます。

</details>

**問6.** SQLで、GROUP BYでグループ化した結果の集計値に対して条件を指定する句はどれでしょう？

1. WHERE
2. ORDER BY
3. HAVING
4. DISTINCT

<details><summary>答えと解説</summary>

正解: **3**

グループ化後の集計結果（COUNTやSUMなど）に条件を付けるのはHAVING句です。WHEREはグループ化の前に行を絞り込む句なので集計値には使えず、ORDER BYは並べ替え、DISTINCTは重複行の除去の指定で、条件を書く句ではありません。

</details>

**問7.** トランザクションのACID特性のうち、「処理がすべて実行されるか、まったく実行されないかのどちらかであること」を保証する性質はどれでしょう？

1. 一貫性（Consistency）
2. 原子性（Atomicity）
3. 独立性（Isolation）
4. 耐久性（Durability）

<details><summary>答えと解説</summary>

正解: **2**

全か無かを保証するのは原子性です。一貫性はデータの整合性条件が常に保たれること、独立性は複数のトランザクションが互いの途中結果に干渉しないこと、耐久性はコミット済みの結果が障害後も失われないことを指します。

</details>

**問8.** 磁気ディスクの媒体障害が起きたデータベースの回復手順として、適切なものはどれでしょう？

1. 更新前ログを使って、障害直前の更新をすべて取り消す
2. 直前のチェックポイントまでロールバックする
3. 障害時点の主記憶の内容をダンプして復元する
4. バックアップからデータベースを復元し、更新後ログでバックアップ取得以降の更新を再現する

<details><summary>答えと解説</summary>

正解: **4**

媒体障害ではディスク上のデータ自体が失われるため、まずバックアップで復元し、更新後ログを使って障害直前まで更新を再現するロールフォワードを行います。更新前ログによる取り消し（ロールバック）はトランザクション障害時の処理で、主記憶のダンプでは失われたディスクの内容は戻せません。

</details>

**問9.** 排他制御における共有ロックと専有ロックの関係として、適切なものはどれでしょう？

1. 共有ロック同士は同時にかけられるが、専有ロックは他のどのロックとも両立しない
2. 専有ロック同士は同時にかけられる
3. 共有ロックと専有ロックは常に両立する
4. どの組み合わせのロックも互いに両立しない

<details><summary>答えと解説</summary>

正解: **1**

読み取り用の共有ロックは複数のトランザクションが同時に取得できますが、更新用の専有ロックは共有・専有のどちらとも両立しません。専有同士が両立すると更新が衝突してしまい、逆に共有同士まで禁止すると読み取りの同時実行性が不必要に下がります。

</details>

**問10.** 外部割込みに分類されるものはどれでしょう？

1. ゼロによる除算
2. 入出力動作の完了
3. ページフォールト
4. 存在しない命令コードの実行

<details><summary>答えと解説</summary>

正解: **2**

外部割込みは実行中のプログラム以外の要因で発生する割込みで、入出力完了やタイマによる割込みが代表例です。ゼロ除算・ページフォールト・不正命令の実行は、いずれも実行中の命令そのものが原因で起こる内部割込みに分類されます。

</details>

## 3. 信頼性・性能・計算問題ドリル

本編の第6章（信頼性と性能）の総仕上げです。計算問題の落とし穴トップ3は、①直列は稼働率の掛け算、並列は「1−(1−a)の2乗」と故障する側から考える、②稼働率はMTBF÷(MTBF＋MTTR)で、分母にMTTRを足し忘れない、③クリティカルパスは「最長」の経路（最短ではない）、です。待ち行列はまず利用率ρを確かめてから公式に入れる手順を固定しましょう。本章の解説にはすべて計算過程を載せているので、答え合わせでは数値だけでなく立式が合っていたかまで確認してから過去問に進んでください。

### 確認問題

**問1.** 稼働率0.9の装置を2台直列に接続したシステム全体の稼働率はいくつでしょう？

1. 0.81
2. 0.99
3. 0.9
4. 1.8

<details><summary>答えと解説</summary>

正解: **1**

直列系は2台の両方が動いてはじめて稼働するので、0.9×0.9＝0.81です。0.99は2台を並列にした場合の値、0.9は1台だけのときの値で、1.8は稼働率を足し算してしまった誤りです（確率が1を超えることはありません）。

</details>

**問2.** 稼働率0.9の装置を2台並列（どちらか1台が動けばシステムは稼働）に接続したとき、システム全体の稼働率はいくつでしょう？

1. 0.81
2. 0.9801
3. 0.99
4. 0.9

<details><summary>答えと解説</summary>

正解: **3**

並列系は「2台が同時に故障したとき」だけ停止するので、1−(1−0.9)×(1−0.9)＝1−0.01＝0.99です。0.81は2台直列の値、0.9801は稼働率0.99の装置を2台直列にした値、0.9は1台だけのときの値です。

</details>

**問3.** MTBFが180時間、MTTRが20時間のシステムの稼働率はいくつでしょう？

1. 0.8
2. 0.9
3. 0.1
4. 0.89

<details><summary>答えと解説</summary>

正解: **2**

稼働率＝MTBF÷(MTBF＋MTTR)＝180÷(180＋20)＝180÷200＝0.9です。0.1は不稼働率（MTTR側の割合）、0.8は(180−20)÷200のようにMTTRを引いてしまった誤り、0.89は分母をMTBFのままにして(180−20)÷180と計算した誤りに相当します。

</details>

**問4.** RAID5の説明として、適切なものはどれでしょう？

1. 同じデータを2台のディスクに書き込んで冗長化する
2. データをビット単位で分割し、専用のパリティディスクに誤り訂正情報を記録する
3. データを複数のディスクに分散して書き込むが、冗長情報は持たない
4. データとパリティをブロック単位で全ディスクに分散して記録し、1台の故障までならデータを復元できる

<details><summary>答えと解説</summary>

正解: **4**

RAID5はパリティを特定のディスクに集中させず、データとともに全ディスクへ分散して記録するため、1台までの故障に耐えられます。2台への同一書き込みはRAID1（ミラーリング）、専用パリティディスク方式はRAID3やRAID4、冗長情報のない分散書き込みはRAID0（ストライピング）の説明です。

</details>

**問5.** あるプロジェクトでは、作業A（3日）の後に作業B（4日）を行う流れと、作業C（5日）の後に作業D（3日）を行う流れを並行して進め、両方が完了したらプロジェクト全体が完了します。全体の所要日数は何日でしょう？

1. 7日
2. 15日
3. 8日
4. 5日

<details><summary>答えと解説</summary>

正解: **3**

A→Bの経路は3＋4＝7日、C→Dの経路は5＋3＝8日です。並行作業では最も長い経路（クリティカルパス）が全体の所要日数を決めるので8日になります。7日は短い方の経路の値、15日は全作業を直列に足した値、5日は最長の単一作業の日数にすぎません。

</details>

**問6.** M/M/1の待ち行列モデルで、窓口の利用率が0.5、平均サービス時間が10ミリ秒のとき、平均待ち時間は何ミリ秒でしょう？

1. 5ミリ秒
2. 10ミリ秒
3. 20ミリ秒
4. 2.5ミリ秒

<details><summary>答えと解説</summary>

正解: **2**

平均待ち時間＝利用率÷(1−利用率)×平均サービス時間＝0.5÷0.5×10＝1×10＝10ミリ秒です。5ミリ秒は利用率×サービス時間とした誤り、20ミリ秒は待ち時間にサービス時間を加えた平均応答時間、2.5ミリ秒は係数の掛け違いです。

</details>

**問7.** 1命令の平均実行時間が20ナノ秒のCPUの処理性能は何MIPSでしょう？

1. 50MIPS
2. 20MIPS
3. 5MIPS
4. 200MIPS

<details><summary>答えと解説</summary>

正解: **1**

MIPSは1秒間に実行できる命令数を百万単位で表した値です。1秒÷20ナノ秒＝10億÷20＝5,000万命令／秒＝50MIPSになります。20MIPSは実行時間の数字をそのまま使った誤りで、5MIPSや200MIPSはナノ秒から秒への桁の換算を誤った値です。

</details>

**問8.** 「信号制御システムが故障したら、信号をすべて赤にして交通を停止させる」という設計が該当する考え方はどれでしょう？

1. フェールソフト
2. フォールトトレラント
3. フールプルーフ
4. フェールセーフ

<details><summary>答えと解説</summary>

正解: **4**

故障したときにシステムを安全な側に倒すのがフェールセーフです。フェールソフトは一部の機能を縮退させながら運転を続ける考え方、フォールトトレラントは冗長化などによって故障しても機能を維持する考え方、フールプルーフは利用者の誤操作をそもそも受け付けない設計を指します。

</details>

**問9.** 稼働率0.9の装置2台からなる直列システムについて、各装置をそれぞれ2重化（2台並列）した構成に変更すると、システム全体の稼働率はいくつになるでしょう？

1. 0.81
2. 0.99
3. 0.9801
4. 0.9999

<details><summary>答えと解説</summary>

正解: **3**

2重化した各部分の稼働率は1−(1−0.9)×(1−0.9)＝0.99になり、それが2段直列なので0.99×0.99＝0.9801です。0.81は2重化する前の値、0.99は並列部分1段だけの値、0.9999は0.99の部分をさらに並列とみなして計算した誤りです。

</details>

**問10.** 1件あたりCPU時間を20ミリ秒使うトランザクションを処理するシステムで、CPU利用率を80％以下に抑えたいとき、1秒間に処理できる最大件数は何件でしょう？

1. 50件
2. 40件
3. 80件
4. 25件

<details><summary>答えと解説</summary>

正解: **2**

1秒間に使ってよいCPU時間は1,000ミリ秒×0.8＝800ミリ秒で、800÷20＝40件が上限です。50件は利用率100％まで使った場合の値、80件は1件あたりを10ミリ秒と取り違えた値、25件は利用率を50％として計算した場合の値です。

</details>

## 4. マネジメント・ストラテジ・法務ドリル

本編の第7章（開発・マネジメント・監査）と第8章（ストラテジ・法務）の総仕上げです。落とし穴トップ3は、①インシデント管理は「迅速な復旧」・問題管理は「根本原因の除去」と目的がちがう、②著作権法が守るのはプログラムの「表現」で、アルゴリズムやプログラム言語は対象外、③システム監査人に必要なのは被監査部門からの独立性、です。この分野は用語の「目的」を自分の言葉で言えれば確実に得点できる範囲なので、間違えた問題は第7・8章に戻って意味から確認しましょう。

### 確認問題

**問1.** WBS（Work Breakdown Structure）の説明として、適切なものはどれでしょう？

1. 作業ごとの担当者と費用を一覧表にまとめたもの
2. 作業の前後関係を矢印で表した図
3. 作業の開始・終了時期を帯状のグラフで表した図
4. プロジェクトの成果物や作業を階層的に分解して整理したもの

<details><summary>答えと解説</summary>

正解: **4**

WBSは作業を漏れなく洗い出すために、成果物や作業をトップダウンで階層的に分解したものです。前後関係を矢印で表すのはアローダイアグラム、開始・終了時期を帯状に表すのはガントチャートで、担当者や費用の一覧はWBSを基に作る別の管理資料です。

</details>

**問2.** プロジェクトのリスク対応のうち、損害保険に加入して損失発生時の影響を第三者に移すものはどれでしょう？

1. 回避
2. 転嫁
3. 軽減
4. 受容

<details><summary>答えと解説</summary>

正解: **2**

保険や外部委託などでリスクの影響を第三者に移すのは転嫁です。回避はリスクの原因となる活動自体をやめること、軽減は発生確率や影響度を下げる対策を打つこと、受容は対策を取らずリスクを受け入れることを指します。

</details>

**問3.** ITサービスマネジメントにおけるインシデント管理の目的として、適切なものはどれでしょう？

1. 中断したサービスを可能な限り迅速に回復させ、事業への影響を最小限に抑える
2. 障害の根本原因を特定して恒久的に取り除く
3. 変更作業を評価・承認して計画的に実施する
4. サービスを構成する機器や設定の情報を正確に記録・維持する

<details><summary>答えと解説</summary>

正解: **1**

インシデント管理の目的はサービスの迅速な復旧です。根本原因の特定と除去は問題管理、変更の評価・承認は変更管理、構成情報の記録・維持は構成管理の役割で、復旧より原因究明を優先すると利用者への影響が長引いてしまいます。

</details>

**問4.** SLA（Service Level Agreement）の説明として、適切なものはどれでしょう？

1. サービス提供者の社内向けの作業手順書
2. システム開発を委託する際の請負契約書
3. 稼働率や復旧時間など、サービスの水準について提供者と利用者が合意した文書
4. 障害発生時の関係者への連絡網

<details><summary>答えと解説</summary>

正解: **3**

SLAは稼働率・復旧時間・サポート時間帯などのサービス水準を定め、提供者と利用者が合意する文書です。社内向けの手順書や連絡網はサービス水準の合意そのものではなく、請負契約書は開発業務の契約であってSLAとは別のものです。

</details>

**問5.** システム監査人の行動として、適切なものはどれでしょう？

1. 被監査部門の業務を兼任して内情に詳しくなる
2. 被監査部門から独立した立場で客観的に評価する
3. 指摘した問題点を監査人自身の手で修正する
4. 監査結果を被監査部門だけに報告して完了とする

<details><summary>答えと解説</summary>

正解: **2**

システム監査人には外観上も精神上も独立性が求められ、被監査部門から独立した立場で客観的に評価します。業務の兼任や自ら修正を行うことは独立性を損なう行為で、監査結果は監査を依頼した経営者などに報告するのが原則です。

</details>

**問6.** 著作権法でソフトウェア関連の保護対象となるものはどれでしょう？

1. プログラム言語そのもの
2. アルゴリズム（解法）
3. 通信プロトコルなどの規約
4. ソースコードなどのプログラムの表現

<details><summary>答えと解説</summary>

正解: **4**

著作権法が保護するのは創作的な「表現」であり、プログラムそのもの（ソースコードなど）は著作物として保護されます。一方、プログラム言語・規約（プロトコルなど）・解法（アルゴリズム）は、著作権法で明示的に保護対象から除かれています。

</details>

**問7.** 不正アクセス禁止法で禁止されている行為はどれでしょう？

1. 他人のIDとパスワードを無断で使い、ネットワーク経由でサーバにログインする行為
2. コンピュータウイルスを作成する行為
3. 業務で知った他社の営業秘密を漏えいする行為
4. 同意のない相手に大量の広告メールを送信する行為

<details><summary>答えと解説</summary>

正解: **1**

不正アクセス禁止法は、他人の識別符号（IDやパスワード）の無断使用や、セキュリティ上の弱点を突いたアクセス制御の突破を禁じています。ウイルスの作成は刑法（不正指令電磁的記録に関する罪）、営業秘密の漏えいは不正競争防止法、広告メールの規制は特定電子メール法の対象です。

</details>

**問8.** 個人情報保護法における「個人情報」に該当するものはどれでしょう？

1. 法人の財務情報
2. 統計処理されて個人を識別できなくなったデータ
3. 生存する個人を識別できる氏名・生年月日などの情報
4. 死者に関する記録の全般

<details><summary>答えと解説</summary>

正解: **3**

個人情報は「生存する個人に関する情報」であって、氏名や生年月日などにより特定の個人を識別できるものです。法人そのものの情報や、個人を識別できない統計データは該当せず、死者に関する情報も原則として対象外です。

</details>

**問9.** SWOT分析の説明として、適切なものはどれでしょう？

1. 市場成長率と市場占有率の2軸で事業を4象限に分類する
2. 自社の強み・弱みと、外部環境の機会・脅威を整理して戦略を立案する
3. 顧客・競合・自社の3つの視点から事業環境を分析する
4. 政治・経済・社会・技術の4つの外部要因を分析する

<details><summary>答えと解説</summary>

正解: **2**

SWOTはStrengths（強み）・Weaknesses（弱み）・Opportunities（機会）・Threats（脅威）の頭文字で、内部要因と外部要因を組み合わせて戦略を導く手法です。4象限の事業分類はPPM、顧客・競合・自社の3視点は3C分析、政治・経済・社会・技術の分析はPEST分析の説明です。

</details>

**問10.** アジャイル開発の特徴として、適切なものはどれでしょう？

1. 短い反復で動くソフトウェアを繰り返しリリースし、変化する要求に対応する
2. すべての要件を確定させてから、設計・実装・テストを一方向に進める
3. 工程ごとに成果物を凍結し、後工程からの変更を一切認めない
4. 動くソフトウェアよりも網羅的なドキュメントの作成を優先する

<details><summary>答えと解説</summary>

正解: **1**

アジャイル開発は短いサイクルで動くソフトウェアを提供し、フィードバックを受けながら要求の変化に対応します。要件をすべて確定してから一方向に進めるのはウォーターフォール型の説明で、変更を一切認めない姿勢やドキュメント最優先の姿勢は、動くソフトウェアと変化への対応を重視するアジャイルの価値観とは逆です。

</details>
