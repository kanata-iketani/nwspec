# 第1章 ネスペ試験のきほんと過去問学習戦略

勉強を始める前に、ネスペ試験の全体像（4区分すべて60点・山場は午後）と、手持ちの過去問を最大限活かす学習サイクルを知る章です。

## 1. ネスペ試験ってどんな試験？

**ネットワークスペシャリスト試験（ネスペ）**は、IPA（情報処理推進機構）が実施する国家試験で、IT 系資格の中でも最難関クラスの「高度試験」のひとつです。年1回、**春（4月）**に実施されます。

### 1日の時間割（午前Ⅰ免除なしの場合）

| 区分 | 時間 | 形式 | 合格基準 |
|---|---|---|---|
| 午前Ⅰ | 50分 | 4択 30問（IT全般） | 60点 |
| 午前Ⅱ | 40分 | 4択 25問（ネットワーク専門） | 60点 |
| 午後Ⅰ | 90分 | 記述式 3問中2問選択 | 60点 |
| 午後Ⅱ | 120分 | 記述式 2問中1問選択 | 60点 |

**4つすべてで60点以上**を取る必要があり、どれか1つでも落とすとその時点で不合格（以降は採点されません）。

### 免除なしの戦い方

基本情報を持っていなくても心配いりません。午前Ⅰは「広く浅く」の4択なので、この講座の第2〜8章で基礎から固めれば十分戦えます。本丸は**午後の記述式**で、ここは知識に加えて「長文の事例を読み解く力」が問われます。🟡 まずは「4区分すべて60点」「山場は午後」という全体像を頭に入れましょう。

### 確認問題

**問1.** ネットワークスペシャリスト試験について、正しいものはどれでしょう？

1. すべての区分がマークシート式である
2. 合計点が基準を超えていれば、区分ごとの点数は問われない
3. 午前Ⅰ〜午後Ⅱの4区分すべてで基準点（60点）以上が必要である
4. 年に2回受験のチャンスがある

<details><summary>答えと解説</summary>

正解: **3**

4区分すべてで60点以上が必要で、1つでも落とすと以降は採点されず不合格です。午後Ⅰ・午後Ⅱは記述式なのでマークシートだけではなく、実施は年1回（春）です。「全区分60点」が合否のルールだと覚えてください。

</details>

**問2.** 基本情報技術者を持っていない受験者にとって、この試験の正しい捉え方はどれでしょう？

1. 午前Ⅰが免除されるので対策は不要である
2. 午前Ⅰは広く浅い4択なので、基礎から順に学べば十分対応できる
3. 基本情報に合格してからでないと受験できない
4. 午前Ⅰだけ合格基準が80点に上がる

<details><summary>答えと解説</summary>

正解: **2**

受験資格に制限はなく、誰でもいきなりネスペを受けられます。午前Ⅰの免除は応用情報合格などの条件を満たした人だけなので、免除なしの場合は対策が必要ですが、出題は「広く浅く」なので基礎からの積み上げで十分です。合格基準はどの区分も60点です。

</details>

**問3.** この試験の「山場」と言われるのはどこで、何が問われるでしょう？

1. 午前Ⅰ。計算問題が最難関だから
2. 午前Ⅱ。問題数が最も多いから
3. 午後。長文の事例を読み解いて記述で答える力が問われるから
4. 山場はなく、全区分同じ難易度である

<details><summary>答えと解説</summary>

正解: **3**

合否を分けるのは記述式の午後Ⅰ・午後Ⅱです。ネットワークの知識そのものに加えて、数ページの事例（企業のネットワーク構成や課題）を読み解き、指定字数で答える力が必要です。この講座では第27〜29章で午後対策を、🎤口頭試問で記述の練習をします。

</details>

## 2. 手持ちの過去問を最強の教材にする方法

### 過去問は「最後の模試」ではなく「毎日の教材」

手持ちの過去問集は、直前期まで取っておく必要はありません。むしろ学習の中心に据えます。おすすめは次の3ステップのサイクルです。

| ステップ | やること |
|---|---|
| ① インプット | この講座で章を読み、4択で理解を確認する |
| ② 過去問 | いま学んだ章に対応する過去問を解く |
| ③ 振り返り | 誤答をにがて帳と照合し、弱点を特定して解き直す |

### 午前と午後で使い方を変える

午前問題は過去の問題からの再出題が多いので、**直近数年分を何周も回す**のが王道です。1問あたり数十秒で正誤を判断できるまで繰り返します。午後問題は量より質で、**必ず時間を計り、答案を実際に手で書く**こと。頭の中で「分かったつもり」になるのが最大の落とし穴です。

> 💡 コツ：過去問で間違えた分野は、この講座の該当章に戻って読み直すと記憶が定着します。

🔴 「講座でインプット→対応する過去問を解く→誤答をにがて帳と照合」のサイクルを、今日から回し始めましょう。

### 確認問題

**問1.** 過去問集の使い方として、この講座が勧める方法はどれでしょう？

1. 実力が仕上がるまで温存し、試験直前に初めて開く
2. 章を学ぶたびに対応する過去問を解き、誤答を記録して解き直す
3. 解説だけを読み、問題は解かずに暗記する
4. 午後問題だけを解き、午前問題は使わない

<details><summary>答えと解説</summary>

正解: **2**

過去問は学習サイクルの中心に置き、インプット→対応する過去問→誤答の振り返り、を章ごとに回すのが効果的です。直前まで温存すると弱点の発見が遅れ、解説の暗記だけでは初見の問題に対応できません。午前・午後の両方に過去問演習が必要です。

</details>

**問2.** 午前問題（4択）の過去問演習として、最も効果的な方法はどれでしょう？

1. 10年以上前の問題を優先して解く
2. 1回解いて正解した問題は二度と見ない
3. 毎回じっくり時間をかけて1問ずつノートにまとめる
4. 直近数年分を、短時間で正誤を判断できるまで繰り返し周回する

<details><summary>答えと解説</summary>

正解: **4**

午前問題は過去の問題からの再出題が多いため、直近数年分の周回が最も効率的です。古すぎる問題は技術動向が変わっていることがあり、1回正解しただけでは定着したとは言えません。午前は問題数が多いので、1問ごとに重いノートを作るより回転数を上げる方が得点に直結します。

</details>

**問3.** 午後問題（記述式）の演習方法として、最も適切なものはどれでしょう？

1. 時間を計り、答案を実際に手で書いて解く
2. 設問と模範解答を交互に眺めて流れをつかむ
3. 頭の中で解答の方向性を思い浮かべたら次の問題へ進む
4. 本文は読まず、設問文だけで答えを推測する練習をする

<details><summary>答えと解説</summary>

正解: **1**

午後は制限時間内に指定字数で書き切る力が問われるため、時間を計って実際に書く練習が不可欠です。眺めるだけ・頭の中だけでは「分かったつもり」になりやすく、本番で書けません。本文を読まない練習は、長文読解力という午後の核心を鍛えられません。

</details>

**問4.** 過去問で間違えた問題への対処として、最も学習効果が高いものはどれでしょう？

1. 間違えた問題は相性が悪いと考えて飛ばす
2. 正解の選択肢の記号だけを覚え直す
3. にがて帳など誤答の記録と照合して弱点分野を特定し、該当分野を学び直してから解き直す
4. 同じ問題をその場で正解するまで連続で選び直す

<details><summary>答えと解説</summary>

正解: **3**

誤答は弱点を教えてくれる最高の情報源です。記録と照合して分野ごとの傾向をつかみ、インプットに戻ってから解き直すことで本当の理解になります。飛ばすと弱点が残り、記号の暗記や選択肢の選び直しは、問題の数字や表現が変わると通用しません。

</details>

## 3. 午前Ⅰの戦略：広く浅く60点でいい

### 午前Ⅰは「満点を狙わない」試験

午前Ⅰは4択30問で、テクノロジ系だけでなくマネジメント系・ストラテジ系（経営など）まで、出題範囲がとても広いのが特徴です。しかし合格基準は**60点**。30問中18問正解すればよく、**12問は間違えてもよい**のです。

### 捨て分野の作り方

全範囲を同じ深さで勉強するのは非効率です。濃淡をつけましょう。

- **厚めにやる**：ネットワーク・セキュリティなど本編と重なる分野（午前Ⅱ・午後にもそのまま効く）
- **普通にやる**：2進数・アルゴリズム・データベースなど頻出のテクノロジ系
- **浅くてよい**：細かい法律名や経営理論など、暗記量の割に出題が少ない分野

ただし分野を丸ごと白紙にするのではなく、過去問でよく出る定番の論点だけは拾っておくのが安全です。

### 計算問題との付き合い方

基数変換や稼働率などの計算問題は、出題パターンが毎回ほぼ同じです。解法を一度身につければ**安定した得点源**になるので、食わず嫌いせず定番パターンだけ押さえましょう。

🟡 合言葉は「広く浅く60点」。満点ではなく18問を確実に取る戦い方です。

### 確認問題

**問1.** 午前Ⅰ試験への取り組み方として、最も適切なものはどれでしょう？

1. 高度試験なので満点を目指して全分野を深く学ぶ
2. 出題範囲が広いので、得意な1分野だけを完璧にする
3. 合格基準の60点を目標に、頻出分野を優先して広く浅く学ぶ
4. 午前Ⅰは配点が低いので対策せずに臨む

<details><summary>答えと解説</summary>

正解: **3**

午前Ⅰは範囲が広い代わりに合格基準は60点なので、頻出分野を優先した「広く浅く」が最適です。満点狙いの深掘りは時間対効果が悪く、1分野だけでは30問の広い出題をカバーできません。午前Ⅰを落とすと以降は採点されないため、無対策は危険です。

</details>

**問2.** 「捨て分野」の作り方として、最も適切なものはどれでしょう？

1. 暗記量の割に出題が少ない分野は浅くし、頻出の定番論点だけ拾う
2. テクノロジ系をすべて捨てて、マネジメント系に集中する
3. 出題数の多い分野から順に捨てて学習量を減らす
4. 捨て分野は一切作らず、全分野を均等に学ぶ

<details><summary>答えと解説</summary>

正解: **1**

濃淡をつけつつ、浅くする分野でも頻出の定番だけは拾うのが安全な捨て方です。テクノロジ系は出題の中心でネスペ本編とも重なるため捨てられません。出題数の多い分野を捨てるのは失点が大きく本末転倒で、均等に学ぶのは時間が足りなくなります。

</details>

**問3.** 午前Ⅰの計算問題（基数変換・稼働率など）への向き合い方として、適切なものはどれでしょう？

1. 毎回新作で傾向がないため、対策のしようがない
2. 電卓が使えるので、解法を覚える必要はない
3. 計算問題はすべて捨てて、知識問題だけで合格点を狙う
4. 出題パターンがほぼ決まっているので、定番の解法を身につけて得点源にする

<details><summary>答えと解説</summary>

正解: **4**

計算問題はパターンの再現性が高く、解法を一度身につければ安定した得点源になります。傾向がないというのは誤りで、IPA の試験では電卓は使用できません。計算問題を全部捨てると合格ラインの確保が難しくなるため、定番パターンだけでも押さえるべきです。

</details>

**問4.** 午前Ⅰは30問出題で合格基準が60点です。最低何問の正解が必要でしょう？（各問の配点は均等とします）

1. 15問
2. 18問
3. 20問
4. 24問

<details><summary>答えと解説</summary>

正解: **2**

100点満点の60%を30問に当てはめると、30 × 0.6 = 18問です。つまり12問までは間違えられます。15問は50%、20問は約67%、24問は80%に相当し、いずれも「最低ライン」としては正しくありません。

</details>
