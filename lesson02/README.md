# 第2章 コンピュータの基礎（2進数・論理・CPU・メモリ）

ネットワークを学ぶ土台として、コンピュータが情報をどう表現し処理するか（2進数・論理演算・CPU・メモリ）を基本情報レベルから学ぶ章です。基数変換と論理演算は、本編の IP アドレス計算にそのままつながります。

## 1. 2進数と基数変換

### コンピュータはなぜ2進数か

コンピュータの中身は電気信号の ON/OFF だけで動くため、すべての情報を 0 と 1 の2種類で表します。これが**2進数**です。ただし 0 と 1 の羅列は人間には読みにくいので、4桁ごとにまとめて**16進数**（0〜9 と A〜F の16種類の文字）で書くこともよくあります。

### 変換のやり方

| 変換 | 方法 |
|---|---|
| 2進 → 10進 | 右の桁から 1, 2, 4, 8, 16… の重みを掛けて足す |
| 10進 → 2進 | 2で割り続け、余りを下から上へ読む |
| 2進 ⇔ 16進 | 2進数4桁 = 16進数1桁 で対応させる |

例：2進数 1101 は、重みを掛けると 8 + 4 + 0 + 1 = **13**。16進数なら **D** です。

> 💡 コツ：1, 2, 4, 8, 16, 32, 64, 128（2のべき乗）をそらで言えるようにしましょう。基数変換だけでなく、本編の IP アドレスやサブネットの計算が一気に速くなります。

🔴 基数変換はネスペ本編の IP アドレス計算の土台です。手が勝手に動くまで練習しましょう。

### 確認問題

**問1.** 2進数 1010 を10進数で表すといくつでしょう？

1. 8
2. 10
3. 12
4. 20

<details><summary>答えと解説</summary>

正解: **2**

右の桁から重み 1, 2, 4, 8 を掛けて足します。1010 は 8×1 + 4×0 + 2×1 + 1×0 = 8 + 2 = 10 です。8 は 1000、12 は 1100、20 は5桁の 10100 にあたるため、いずれも誤りです。

</details>

**問2.** 10進数 25 を2進数で表すとどれでしょう？

1. 10011
2. 10110
3. 11010
4. 11001

<details><summary>答えと解説</summary>

正解: **4**

25 を2で割り続けると、25÷2=12 余り1、12÷2=6 余り0、6÷2=3 余り0、3÷2=1 余り1、1÷2=0 余り1。余りを下から読むと 11001 です。検算すると 16+8+1=25 で一致します。10011 は 19、10110 は 22、11010 は 26 なので誤りです。

</details>

**問3.** 16進数 FF を10進数で表すといくつでしょう？

1. 155
2. 240
3. 255
4. 256

<details><summary>答えと解説</summary>

正解: **3**

16進数の F は 15 です。FF = 15×16 + 15 = 240 + 15 = 255 となります。240 は F0、256 は桁が1つ増えた 100 にあたります。255 は IP アドレス（8ビットの最大値）として本編でも頻繁に登場する重要な数です。

</details>

**問4.** 2進数 10110100 を16進数で表すとどれでしょう？

1. B4
2. A4
3. D4
4. BC

<details><summary>答えと解説</summary>

正解: **1**

2進数を4桁ずつに区切ると 1011 と 0100。1011 は 8+2+1=11 で 16進数の B、0100 は 4 なので、合わせて B4 です。A4 は 10100100、D4 は 11010100、BC は 10111100 にあたるため誤りです。

</details>

## 2. 論理演算とビット操作

### 3つの基本演算

論理演算は、0（偽）と 1（真）に対する計算です。複数桁のビット列どうしなら、桁ごとに計算します。

| 演算 | 意味 | 結果が1になる条件 |
|---|---|---|
| AND | かつ | 両方が 1 のとき |
| OR | または | 少なくとも一方が 1 のとき |
| XOR | 排他的論理和 | 2つの値が異なるとき |

例：1010 AND 1100 = 1000、1010 OR 1100 = 1110、1010 XOR 1100 = 0110 です。

### ビット操作の定番テクニック

- 特定のビットだけ**取り出す**：AND を使う（マスク）。IP アドレスとサブネットマスクの計算がまさにこれです
- 特定のビットを**1にする**：OR を使う
- 特定のビットを**反転する**：XOR を使う

### シフト演算

ビット列を左右にずらす操作です。整数では、**左に1ビットシフトすると2倍、右に1ビットシフトすると2分の1**（あふれや切り捨てがない場合）になります。例：0011（3）を左に2ビットずらすと 1100（12）で、4倍です。

🔴 AND によるマスクは、本編のサブネット計算で毎回使う最重要テクニックです。

### 確認問題

**問1.** 2進数 1100 と 1010 の AND 演算の結果はどれでしょう？

1. 1110
2. 1000
3. 0110
4. 1010

<details><summary>答えと解説</summary>

正解: **2**

AND は桁ごとに「両方が1のときだけ1」です。左の桁から 1と1→1、1と0→0、0と1→0、0と0→0 で、結果は 1000 です。1110 は OR の結果、0110 は XOR の結果なので混同に注意しましょう。1010 は一方の入力そのままです。

</details>

**問2.** 2進数 1100 と 1010 の XOR 演算の結果はどれでしょう？

1. 0110
2. 1110
3. 1000
4. 0010

<details><summary>答えと解説</summary>

正解: **1**

XOR は桁ごとに「2つの値が異なるときだけ1」です。左から 1と1→0、1と0→1、0と1→1、0と0→0 で、結果は 0110 です。1110 は OR、1000 は AND の結果です。0010 はどの基本演算の結果にもあたりません。

</details>

**問3.** ある正の整数を2進数で表し、あふれが起きない範囲で左に2ビットシフトしました。値はどうなるでしょう？

1. 2倍になる
2. 4分の1になる
3. 4倍になる
4. 変わらない

<details><summary>答えと解説</summary>

正解: **3**

左1ビットシフトで2倍なので、2ビットなら 2×2 = 4倍です。例えば 0011（3）を左に2ビットずらすと 1100（12）になります。2倍は左1ビットシフト、4分の1は右2ビットシフトの結果です。シフトすれば値は変わります。

</details>

**問4.** IP アドレスとサブネットマスクからネットワークアドレスを求めるときに使う論理演算はどれでしょう？

1. OR
2. XOR
3. NOT
4. AND

<details><summary>答えと解説</summary>

正解: **4**

マスクが1の桁だけを取り出したいので AND を使います。IP アドレスとサブネットマスクを桁ごとに AND すると、ホスト部が 0 になりネットワークアドレスが得られます。OR はビットを立てる操作、XOR は反転、NOT は全ビット反転で、取り出しには使いません。

</details>

## 3. CPU の動き（レジスタ・キャッシュ・パイプライン）

### CPU は「読んで・解釈して・実行する」係

CPU（中央処理装置）は、プログラムの命令を1つずつ取り出し（フェッチ）、解読し（デコード）、実行する装置です。この作業のテンポを刻むのが**クロック**で、クロック周波数 2GHz なら1秒間に20億回のテンポで動作します。

### 登場人物の整理

| 部品・仕組み | 役割 |
|---|---|
| レジスタ | CPU 内部にある超高速・極小容量の作業用メモ |
| キャッシュメモリ | CPU と主記憶の速度差を埋める緩衝役。よく使うデータの写しを置く |
| パイプライン | 命令処理の各段階を流れ作業で重ねて実行する高速化の仕組み |

### パイプラインのイメージ

洗濯にたとえると、「洗う・干す・たたむ」を1人分ずつ終わらせるのではなく、1人目を干している間に2人目の洗いを始める方式です。1つの命令にかかる時間は同じでも、単位時間あたりの処理量（スループット）が上がります。

> 💡 コツ：「速い記憶ほど小さくて高価」。レジスタ → キャッシュ → 主記憶の順に、遅く・大きく・安くなります。

🟡 午前Ⅰでは「キャッシュは速度差を埋める」「パイプラインは流れ作業」の2点を押さえれば十分です。

### 確認問題

**問1.** キャッシュメモリを設ける主な目的はどれでしょう？

1. 主記憶の容量を増やすこと
2. 停電時にもデータを保持すること
3. 補助記憶装置の寿命を延ばすこと
4. CPU と主記憶の速度差を埋めること

<details><summary>答えと解説</summary>

正解: **4**

CPU に比べて主記憶は遅いため、よく使うデータの写しを高速なキャッシュに置いて待ち時間を減らします。容量を増やす仕組みではなく、キャッシュは電源を切ると内容が消えるので停電対策にもなりません。補助記憶の寿命とも直接の関係はありません。

</details>

**問2.** パイプライン処理の説明として、適切なものはどれでしょう？

1. 1つの命令が完全に終わってから次の命令を開始する方式
2. 命令処理を複数の段階に分け、異なる命令の各段階を重ねて並行に処理する方式
3. 複数の CPU で同じ命令を同時に実行して結果を照合する方式
4. 使用頻度の高い命令をキャッシュに保存しておく方式

<details><summary>答えと解説</summary>

正解: **2**

パイプラインは「取り出し・解読・実行」などの段階を流れ作業のように重ね、スループットを高める仕組みです。1命令ずつ完了を待つのは逐次処理でパイプラインの逆です。同じ命令を複数 CPU で照合するのは信頼性向上のための多重化、命令の保存はキャッシュの話です。

</details>

**問3.** レジスタの説明として、適切なものはどれでしょう？

1. CPU 内部にある、最も高速だが容量はごくわずかな記憶装置
2. 電源を切ってもデータが消えない大容量の記憶装置
3. 主記憶と補助記憶の間に置かれる緩衝用の記憶装置
4. 画面表示専用のデータを保持する記憶装置

<details><summary>答えと解説</summary>

正解: **1**

レジスタは CPU 内部で演算対象のデータや命令のアドレスなどを一時的に保持する、記憶階層の最上位です。電源を切ると消え、容量もごくわずかです。大容量で不揮発なのは SSD/HDD などの補助記憶の特徴で、主記憶との緩衝役はキャッシュメモリの説明です。

</details>

**問4.** クロック周波数が 1GHz の CPU において、1クロックの周期はどれでしょう？

1. 1マイクロ秒
2. 1ミリ秒
3. 1ナノ秒
4. 1ピコ秒

<details><summary>答えと解説</summary>

正解: **3**

周期は周波数の逆数です。1GHz = 10 の9乗 Hz なので、周期は 1 ÷ 10⁹ 秒 = 10⁻⁹ 秒 = 1ナノ秒です。1マイクロ秒は 1MHz、1ミリ秒は 1kHz に対応し、1ピコ秒なら 1THz になってしまいます。単位の接頭語（k→M→G→T と m→µ→n→p）の対応を押さえましょう。

</details>

## 4. メモリと記憶階層（主記憶・仮想記憶・SSD/HDD）

### 記憶装置は階層構造

記憶装置は「速いほど小さく高価、遅いほど大きく安価」という階層を作っています。

| 階層 | 例 | 特徴 |
|---|---|---|
| レジスタ・キャッシュ | CPU 内部 | 最速・極小 |
| 主記憶（メインメモリ） | DRAM | プログラムとデータの作業場所。電源を切ると消える（**揮発性**） |
| 補助記憶 | SSD・HDD | 電源を切っても消えない（**不揮発性**）。大容量で安いが遅い |

### 仮想記憶

主記憶が足りなくても、補助記憶の一部を主記憶の続きのように見せかけて使う仕組みが**仮想記憶**です。主記憶と補助記憶の間でのデータの出し入れ（ページング）が多発すると、処理が極端に遅くなる**スラッシング**という状態に陥ります。

### SSD と HDD

HDD は磁気ディスクを回転させて読み書きし、SSD はフラッシュメモリに電気的に記録します。SSD は機械的に動く部品がないため高速・静音で衝撃に強く、HDD は容量あたりの価格で有利です。

🟡 「主記憶は揮発性・補助記憶は不揮発性」「仮想記憶は補助記憶を主記憶の延長に見せる仕組み」の2点を押さえましょう。

### 確認問題

**問1.** 記憶装置の「揮発性」の説明として、適切なものはどれでしょう？

1. 読み書きを繰り返すと記憶装置が劣化する性質
2. データが自動的に圧縮される性質
3. 電源を切ると記憶内容が消える性質
4. 温度が上がると処理速度が低下する性質

<details><summary>答えと解説</summary>

正解: **3**

揮発性とは電源供給が止まると内容が失われる性質で、主記憶に使われる DRAM が代表例です。だからこそ、保存したいデータは不揮発性の SSD/HDD に書き込みます。劣化・圧縮・温度の話は揮発性という用語の意味ではありません。

</details>

**問2.** 仮想記憶の説明として、適切なものはどれでしょう？

1. 補助記憶の一部を利用して、実装された主記憶より大きなメモリ空間をプログラムに見せる仕組み
2. 主記憶の内容を定期的に複製してデータ消失に備える仕組み
3. 複数のコンピュータのメモリを合算して1つに見せるネットワーク技術
4. キャッシュメモリを増設して CPU を高速化する仕組み

<details><summary>答えと解説</summary>

正解: **1**

仮想記憶は、補助記憶を主記憶の延長として使い、実際の搭載量より大きなメモリ空間を見せる OS の仕組みです。複製によるバックアップや、複数マシンのメモリ共有とは別の話です。キャッシュの増設はハードウェアの構成変更であり、仮想記憶とは関係ありません。

</details>

**問3.** SSD が HDD より優れている点として、適切なものはどれでしょう？

1. 容量あたりの価格が常に安い
2. 機械的に動く部品がないため、読み書きが速く衝撃にも強い
3. 磁気ディスクの回転数を自由に変えられる
4. 電源を切るとデータが消えるので機密保持に向く

<details><summary>答えと解説</summary>

正解: **2**

SSD はフラッシュメモリに電気的に記録するため駆動部がなく、高速・静音・耐衝撃という利点があります。容量あたりの価格ではむしろ HDD が有利です。磁気ディスクの回転は HDD の仕組みで SSD には存在せず、SSD は不揮発性なので電源を切ってもデータは消えません。

</details>

**問4.** 記憶装置を一般にアクセスが速い順に並べたものはどれでしょう？

1. 主記憶 → レジスタ → キャッシュメモリ → 補助記憶
2. キャッシュメモリ → レジスタ → 補助記憶 → 主記憶
3. 補助記憶 → 主記憶 → キャッシュメモリ → レジスタ
4. レジスタ → キャッシュメモリ → 主記憶 → 補助記憶

<details><summary>答えと解説</summary>

正解: **4**

CPU に近いほど速く、レジスタ → キャッシュ → 主記憶 → 補助記憶の順です。同時に「速いほど容量が小さく高価」という関係も成り立ちます。他の選択肢はいずれも順序が入れ替わっており、特に最下位（最も遅い）が補助記憶である点は固定で覚えてください。

</details>
