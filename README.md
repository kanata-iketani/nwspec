# ネスペどうじょう 🌐

基本情報を持っていない状態（午前Ⅰ免除なし）から、ネットワークスペシャリスト試験の合格を目指すブラウザ学習アプリです。左に教科書、右に一問一答（4択）。答えるとその場で判定と解説が出ます。

**このアプリは「インプットと理解確認」を担当します。** 仕上げのアウトプットは手持ちの過去問で行う前提の設計です（過去問の回し方は第1章で解説）。

## 使い方

```sh
cd nwspec
go -C app run .
```

ブラウザで <http://127.0.0.1:8085> を開いてください。必要なのは [Go](https://go.dev/dl/) 1.22+ だけです。

## 構成（全33章・127チャプター・602問）

| パート | 章 | 対応する試験 |
|---|---|---|
| 戦略と過去問の使い方 | 第1章 | 全体 |
| IT基礎（基本情報レベルから） | 第2〜8章 | **午前Ⅰ** |
| ネットワーク本編 | 第9〜26章 | **午前Ⅱ + 午後の知識** |
| 午後対策（長文読解と記述） | 第27〜29章 | **午後Ⅰ・午後Ⅱ** |
| ドリル | 第30〜31章 | 午前Ⅰ・Ⅱ |
| 本試験形式の模試 | 第32〜33章 | 午前Ⅰ(30問)・午前Ⅱ(25問) |

- 全問正解でチャプタークリア ✅。間違えた問題は **にがて帳** に自動記録され、ワンクリックで解き直せます
- 記述対策には 🎤 **口頭試問**（AI が別角度の記述問題を出題し、答えを採点）が特に有効です

## AI の先生（ローカルに [Claude Code](https://claude.com/claude-code) がある場合）

「🙋 質問」からいつでも使えます。なくても学習機能はすべて使えます。

| 機能 | 何をしてくれるか |
|---|---|
| 💬 質問 | いま学んでいるチャプターの文脈で、初心者向けにかみ砕いて回答 |
| 🎤 口頭試問 | **午後試験の記述力を鍛える**別角度の記述問題を出題し、答えを採点 |
| 📝 弱点まとめ | 全誤答・全質問を分析し、「苦手分野トップ3・次にやること」をノート化 |
| 🎯 専用復習問題 | 誤答の多い分野を自動特定し、同じ論点の別角度類題で専用章を生成 |
| 📰 最新動向ノート | AI が Web 検索で試験日程・出題傾向・新技術トピックを調べて出典付きノートを作成 |

AI の利用量はリポジトリ直下の `ai-config.json` で管理できます（GitHub 上で編集すると起動中のアプリに約10分で自動反映。`-1`=無制限 / `0`=停止 / 正の数=1日の上限）。

## 教材データ

正データは `lessonNN/chMM.json`（教科書 `text` + 4択 `quiz`）。編集後は `go run ./tools/coursegen` で検証します。
